# Browser

- Use an existing development daemon or start `pnpm dev:daemon`, then run `pnpm dev:web`.
- Connect new browser clients through `pnpm dev:pair`.
- Use hot reload where supported. Follow the [development guide](../../../../docs/development.md)
  for changes requiring a rebuild or restart.
- Validate using the [runtime skill's](../SKILL.md) tool-selection and readiness guidance.

Prefer the harness's in-app browser when available and suitable. Use another supported browser
tool when the task requires it or the in-app browser lacks a needed capability.
