---
name: ui-review
description: Build or review visible Porcelain UI on web, desktop, or mobile using the product's checklist for hierarchy, copy, feedback, controls, and verification.
---

1. Lead with the current work. Read the feature map and use the nearest component or approved board. Group the content around the task and its next action.
2. Let labels do the work. Delete repeated headings, copy, icons and badges. Keep first-use steps, constraints, choices, consequences and accessible names.
3. Keep feedback quiet. A page the person opened can show one small delayed spinner. Skip skeletons, loading copy and background-read messages. Keep the last value when a background read fails, and keep content readable offline while writes are disabled. Put a recoverable error beside its action. Give empty states one line and at most one button. Send user-caused completion through the client's notification owner. Copy acknowledgments use a title without the clipboard value.
4. Keep controls and chrome consistent. Use the shared pending state to preserve the control's name and size and expose busy status. Follow platform chrome, focus, contrast, touch targets, and reduced motion.
5. Drive the entry and return paths with the verification skill. Check realistic content, narrow widths, pending, failure, empty and offline states wherever they affect the change. Record the surfaces and states exercised.
