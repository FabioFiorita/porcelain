# Contributing

Issues and focused pull requests are welcome. Explain the behavior being changed and the evidence
observed rather than preserving an existing pattern for its own sake.

Start with [AGENTS.md](AGENTS.md) for repository boundaries and
[docs/development.md](docs/development.md) for the supported setup, isolated profiles, Worktrees,
and validation commands. Cross-runtime changes may also need
[docs/architecture.md](docs/architecture.md); remote operations and releases have dedicated guides
in [docs/remote-access.md](docs/remote-access.md) and [docs/release.md](docs/release.md).

Keep a change coherent and unrelated cleanup separate. Run the closest useful formatter, test,
typecheck, build, or runtime proof for the affected surface, and include the result and any remaining
uncertainty in the pull request. By contributing, you agree that your work is licensed under the
[MIT License](LICENSE).
