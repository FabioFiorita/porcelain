# Domain language

These terms describe the human-facing model. Their fields and operations belong in the
[contracts](../packages/contracts/src/), not in this glossary.

| Term | Meaning in Porcelain |
| --- | --- |
| Environment | A connected workspace where projects, files, and commands live, locally or remotely. |
| Project | A Git repository and its worktrees. |
| Worktree | A checkout of a project, allowing separate work to happen alongside other checkouts. |
| Changes | The surface to inspect differences and organize them into review layers. |
| Canvas | A surface for explanations, visuals, and interactive content that developers can explore and refine. |
| Reviewed | A file marked as checked by the developer to track progress through a review. |
| History | The surface to see past commits and the changes made to individual files. |
| Navigation profile | A developer’s pinned files and hidden paths for a project. |
| Action | A saved command developers can run with a button. |
| Pairing | Connecting a device to an Environment and granting it access. |
