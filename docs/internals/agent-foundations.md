# Agent foundations — current ownership map

This is the checked index for the cross-cutting agent foundations. It answers three questions for
each inventory row: who owns the behavior now, where the durable source lives, and which proof and
gate protect it. The map is an index, not a second implementation or a replacement for the focused
procedure named in a row.

The `Legacy source` column is intentionally the only place a complete row may name the retired
foundation material. AGT-003 uses those entries for its deletion search. `Permanent source` and
`Proof` must point at current repository documentation, code, tests, or procedures. The former
invariant documents are not silently treated as the permanent owner of any complete row.

No new per-domain security mirror is introduced here. In particular, Review keeps the sources landed
by REV-010 (`docs/internals/app-shell.md`, the Review implementation, and its tests) rather than
gaining a parallel `review-security.md` document.

## Discovery

- The always-on delivery loop and escalation rules live in root [`AGENTS.md`](../../AGENTS.md).
- Browser, mobile, and release procedure detail lives in the focused
  [`web-e2e`](../../.agents/skills/web-e2e/SKILL.md), [`mobile`](../../.agents/skills/mobile/SKILL.md),
  and [`releasing`](../../.agents/skills/releasing/SKILL.md) procedures.
- Domain/supporting-region docs, implementation boundaries, tests, and mechanical gates are linked
  row-by-row below. Use the narrowest proof named by the row before reaching for the campaign-wide
  gate.
