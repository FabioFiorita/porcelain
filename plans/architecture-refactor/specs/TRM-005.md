# TRM-005 — Move the mobile Terminal adapter to shared stream semantics

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: terminal
- Depends on: TRM-003, TRM-004, TST-001, RT-005
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [008](../decisions/008-give-each-client-state-one-owner.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

The native Terminal adapter uses TRM-003 for canonical stream behavior and deletes mobile-local request correlation, attachment tracking and raw terminal frame handling.

## Why this unit exists

`lib/daemon/terminal.ts` independently owns every request id, timeout, attached-id set, reconnect loop and frame subscription, while `features/terminal/use-terminals.ts` owns a second consumer lifetime and roster attachment loop.

## Current behavior and evidence

- `terminal.ts` implements create/attach/detach/write/resize/kill/paste and `subscribeTerminalStream` directly over `daemonSession`.
- `use-terminals.ts` reference-counts one subscription, polls `terminalSessions`, hydrates `terminal-store`, and attaches Project sessions.
- Native xterm/Porcelain terminal views and input stores are presentation/platform code and remain mobile-owned.

## Scope

Create `apps/mobile/src/features/terminal/{terminal-stream-adapter,terminal-roster,terminal-recovery,index}.ts`; move feature callers; delete `lib/daemon/terminal.ts` and its raw terminal-frame subscriptions after complete migration; remove Terminal-only local descriptor types replaced by `@porcelain/contracts/terminal`.

## Non-goals

Do not change native module/xterm behavior, foreground policy, PTY daemon operation, action workflows, local input/composer stores, or terminal byte caps.

## Target ownership and public surface

- `terminal-stream-adapter.ts` exports `useMobileTerminalStream` plus `createMobileTerminalAdapter`, injecting React Native session lifecycle, Expo request-id source and native engine callbacks into TRM-003.
- `terminal-roster.ts` exports `useTerminals`, `useRenameTerminal`, and `useTerminalActions`; roster stays Query-backed and Project-filtered, while rename/actions use canonical contract descriptors and typed effects.
- `terminal-recovery.ts` exports `applyTerminalRecovery`, translating shared reattach/refresh-roster effects to native session/query work once per provider.
- `index.ts` is the only Terminal feature public surface; native views do not import `lib/daemon/terminal`.

## Behavior to preserve

Keep one stream subscription across route transitions, scrollback before data, attached-session idempotence, foreground/background reconnect recovery, five-second roster poll, external exit, write chunk limit, paste results, rename/input UI and native accessibility/test IDs.

## Legacy behavior to delete

Delete `apps/mobile/src/lib/daemon/terminal.ts`, `attachedIds`, `whenOpen`, request maps/correlation, raw `daemonSession.subscribe` terminal branches, reconnect attach loop, and direct Terminal descriptor imports from mobile presentation.

## Ordered implementation

1. Verify TRM-003, TRM-004 and RT-005 are landed.
2. Bind native session/engine callbacks and roster hooks to TRM-003; mount recovery once in the Terminal feature/provider tree.
3. Move all Terminal component imports, delete the local module and raw frame code, then run the zero-import search.

## Tests

- Adapter tests prove foreground/background reconnect, attach/paste correlation, timeout/close, gap recovery, scrollback/data order and stale reply rejection with fake native transport.
- Roster tests retain one-consumer lifecycle, Project filtering, polling, external exit, rename/actions and recovery refetch.
- Retain native-terminal buffer/view/engine/composer/key tests and assert visible pending/failure behavior against the feature boundary.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../mobile/src/features/terminal ../mobile/src/lib/daemon/session-native-adapter.test.ts`.
- Run `pnpm --dir apps/mobile typecheck` and `pnpm lint`.
- Run `rg -n "lib/daemon/terminal|attachedIds|subscribeTerminalStream|terminal:(create|attach|data|exit|attached)" apps/mobile/src`; it returns no result.

## Forbidden shortcuts

Do not keep a mobile correlation/reattach fork, map stream bytes to query invalidation, use raw frames in components, or retain a compatibility terminal parser.

## Completion criteria

- [ ] Mobile Terminal uses the shared state machine with one native adapter/recovery owner.
- [ ] Local stream/correlation paths are deleted while native presentation behavior remains proven.
- [ ] Focused tests, mobile typecheck, lint and deletion search pass; the unit is committed.

## Handoff

The Terminal stream exemplar is complete; TRM-006 may cut over remaining request/response surfaces without recreating stream state.
