# CON-004 — Move Files procedure schemas into the Files contract module

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: `files`
- Depends on: `CON-003` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

`files.procedures.ts` owns exact schemas/kinds for 15 current Files procedures and reduces the
ledger from 97 to 82 entries.

## Why this unit exists

Files inputs/outputs are split between `repos.ts`, `files.ts` and `settings.ts`; the current file-view
schema is partial wire coverage.

## Current behavior and evidence

Names: `readDir`, `hidePath`, `unhidePath`, `pinPath`, `unpinPath`, `pinnedEntries`, `readFile`,
`previewHtml`, `writeTextFile`, `createFile`, `createFolder`, `renamePath`, `duplicatePath`,
`trashPath`, `repoScope`.

## Scope

Create `packages/contracts/src/files/{files.contract,files.procedures,index}.ts`, tests and ledger
removal only.

## Non-goals

Do not move Search, filesystem adapters, safe-path rules, watches, routers, output parsing or clients.

## Target ownership and public surface

Declare query kinds for `readDir`, `pinnedEntries`, `readFile`, `previewHtml`, `repoScope`; mutations
for the other ten names. `files.contract.ts` owns strict DirEntry/FileView/RepoScope values and exact
path/content/create/rename inputs.

## Behavior to preserve

Keep current file-view discriminator, nullable HTML preview, relative/absolute path value behavior and
all current input bounds.

## Legacy behavior to delete

Delete only the 15 Files ledger entries; do not delete old horizontal values before `CON-021`.

## Ordered implementation

1. Move/refine all Files wire values into `files.contract.ts`.
2. Create 15-entry `filesProcedures` with exact kinds and exports.
3. Remove the ledger entries and set unmigrated count expectation to 82.

## Tests

Add Files contract tests for every input/output, especially each FileView branch and invalid scope/path
object shapes.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/files/files.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not include `search*`, use unknown outputs, or expose filesystem/native error objects.

## Completion criteria

- [x] All 15 Files names have exact schema/kind records.
- [x] Ledger count is 82 and Files entries are absent.
- [x] Tests, lint script and diff check pass.

## Handoff

`FIL-001` may add expected failures to one Files contract entry point.
