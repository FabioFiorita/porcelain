# TRM-001 — Define canonical Terminal stream vocabulary

- Status: Draft
- Batch: 2 — focused behavior exemplars
- Domain: terminal
- Depends on: `CON-021`, `ERR-001` (Draft), `RT-005` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Replace the remaining horizontal terminal frame vocabulary with strict Terminal stream commands/events carrying session epoch, sequence, correlation, and declared public failures.

## Why this unit exists

RT-001 preserved terminal's separate stream but only established framing; current `ws-protocol.ts` and `net/session.ts` still mix create/attach/write replies with old transport naming and no explicit recovery vocabulary.

## Current behavior and evidence

The authenticated session currently accepts `terminal:create`, `attach`, `detach`, `write`, `resize`, `kill`, `paste-image`, and `paste-file`; `terminal-manager.ts` fans out `terminal:data` and `terminal:exit`, maintains scrollback/reattachment, and `router/terminal.ts` serves roster/rename. Existing resource limits include 64 sessions, 10-minute exited retention, and 12-hour detached idle retention.

## Scope

Refine `packages/contracts/src/terminal/{terminal.contract,terminal.procedures,terminal.stream}.ts` and focused tests only. Define command/event/correlation values required by TRM-002/003; do not alter runtime code.

## Non-goals

Do not spawn PTYs, alter session/recovery behavior, wire Web/RN transports, change Ghostty/native views, or migrate roster/rename implementation.

## Target ownership and public surface

Commands are strict `terminal:create`, `terminal:attach`, `terminal:detach`, `terminal:write`, `terminal:resize`, `terminal:kill`, `terminal:paste-image`, and `terminal:paste-file`, each with `requestId`; reply/events are strict `terminal:created`, `terminal:attached` (including bounded scrollback), `terminal:data`, `terminal:exit`, and paste result/error. Every stream event has `epoch` and monotonic `sequence` per terminal attachment; `terminalSessions`/`renameTerminal` retain their tRPC records. Errors declare terminal not-found, exited, capacity, invalid-size, and paste-unavailable only when intentional.

## Behavior to preserve

Preserve byte data framing, terminal output ordering, attach scrollback replay, sessions surviving disconnect, roster fields, current size defaults, and all existing resource caps.

## Legacy behavior to delete

Delete terminal command/event declarations from `ws-protocol.ts` and old uncorrelated stream types after TRM-002 switches runtime; no compatibility parser is retained.

## Ordered implementation

1. Transcribe all current command/reply fields and limits into strict Terminal contracts.
2. Add epoch/sequence/request correlation without changing current runtime behavior.
3. Declare exact expected errors and invalid fixtures.
4. Leave old runtime imports intact until TRM-002 atomic stream switch.

## Tests

Test every command/event discriminator, request correlation, epoch/sequence constraints, scrollback/data shape, caps, malformed input, and error payload.

## Forbidden shortcuts

Do not encode terminal output as `session:change`, omit sequence/correlation, use `z.unknown`, or change runtime transport early.

## Completion criteria

- [ ] Commands, events, roster values, errors, epoch, sequence, and correlation are strict contract values.
- [ ] Existing stream limits/reattachment semantics are represented and tested.
- [ ] No runtime transport changed; contract tests/lint pass.

## Handoff

`TRM-002` may replace the daemon PTY gateway atomically against this vocabulary.
