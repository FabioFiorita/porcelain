# AGT-001 — Relocate every Ship responsibility and Audit invariant to current owners

- Status: Draft
- Batch: 8
- Domain: Agent foundations and launch
- Depends on: SUP-001, SUP-002, SUP-003, CLI-001, DAT-001
- Governing decisions: 003, 004, 006, 009, 011, 014, 015
- Primary exemplar: yes

## Objective

Create one indexed, current-owner map for every Ship responsibility and Audit invariant, then make root instructions, focused procedures, docs, tests, and lint gates the discoverable authority before any Ship/Audit deletion.

## Why this unit exists

Ship duplicates delivery-loop guidance and Audit is a cross-cutting invariant router. Their contents must not vanish or remain ambiguous when the skills are retired.

## Current behavior and evidence

- The inventory's Ship table names intent/evidence/gates, autonomy, commit/worktree, browser/mobile proof, dev homes, release, and optional Review publication.
- Its Audit table assigns exact permanent owners: Files, Remote, Terminal, Project Data, Git, CLI support/domains, Review, Actions, Daemon/Desktop, Viewer, and Desktop/Releasing.
- `scripts/lint-audit.mjs` currently enforces only safe external URLs, Git env scrub, and hook env scrub.

## Scope

- Add `docs/internals/agent-foundations.md` with both indexed maps and links to current owner docs/tests/gates.
- Update root/nested `AGENTS.md`, focused procedures, and owner docs only for rows whose destination is complete.
- Add `scripts/lint-foundation-ownership.mjs` to require every map row has an owner, source proof, and gate/test path.

## Non-goals

- Do not delete `.agents/skills/{ship,audit}` or `docs/internals/audit/` in AGT-001.
- Do not move product behavior or loosen any security/resilience invariant.

## Target ownership and public surface

Root `AGENTS.md` owns the Decision-014 delivery loop, autonomy, gates, dev homes/ports/playground, and stop-before-push. `web-e2e`, `mobile`, and `releasing` own their focused procedures. Domain docs/tests own named Audit invariants: Files host/path/hidden/watch limits; Remote listeners/auth/CORS; Terminal PTY/env/stream; Project Data atomic/corruption; Git env/locks; Review containment/CSP; Actions human-run trust; Viewer bounds; Desktop packaging/lifecycle; CLI channel boundary.

## Behavior to preserve

Preserve every real safety/recovery property, command gate, browser/mobile proof rule, release trigger, and optional Review decision. A published Review remains optional and only its publication evidence uses Companion.

## Legacy behavior to delete

Delete no Ship/Audit source in this unit. Delete duplicate prose only after the map marks its target row complete and the new source is linked/tested.

## Ordered implementation

1. Create the map with one row per inventory table row: old source, exact current owner, permanent source path, proof path/command, and removal gate.
2. Add the concise nine-step delivery loop to root `AGENTS.md`: intent, boundary, implement, owned-risk test, evidence, docs/enforcement, gate, commit, stop before push.
3. Move browser/mobile/release detail to the named focused skills; root retains trigger and link only.
4. For every Audit row, add/verify an owner document and named focused test/gate. Link existing `lint-audit.mjs` rules rather than pretending it covers the others.
5. Implement `lint-foundation-ownership.mjs` to parse the map, reject missing owners/proofs/gates, and reject map sources that remain only in Ship/Audit once a row is marked complete.
6. Add it to root lint and test it with valid/missing-owner/missing-proof fixtures.
7. Mark a map row complete only after its target docs, test/gate, and root/focused discovery path are present.

## Tests

- Fixture tests for `lint-foundation-ownership.mjs` cover every required row field.
- Each map row runs its named existing/future owner proof.
- `pnpm lint`, `pnpm agents:check`, and `pnpm agents:doctor` pass.

## Validation and evidence

Review the map row-by-row with source links and command results. A fresh agent must find loop, proof, and gate from root plus relevant focused procedure without reading Ship/Audit.

## Forbidden shortcuts

- Do not summarize an invariant as 'security' or 'tested elsewhere'; use exact owner/proof paths.
- Do not mark a row complete from prose alone.
- Do not delete or weaken Audit checks before the owner test/gate exists.

## Completion criteria

Every inventory Ship/Audit row is indexed with one current owner and proof/gate; root loop and focused procedures are discoverable; the ownership lint and existing foundation checks pass.

## Handoff

AGT-003 may delete Ship/Audit only after AGT-001 map has no incomplete row and AGT-002 Companion changes are landed.
