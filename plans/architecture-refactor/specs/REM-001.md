- Primary exemplar: no

## Objective

Move Remote daemon identity, access, pairing-link, and revoke procedures from direct router/store calls to bound operations with exact public failures.

## Why this unit exists

`router/daemon.ts` directly combines pairing URL policy, access-store secrets, client revocation, and session behavior.

## Current behavior and evidence

`router/daemon.ts` serves daemon/access/pairing/revoke procedures; `stores/access-store.ts` owns version-1 secret-hash access data; `net/admin-token.ts`, daemon identity/version, and session revocation are remote infrastructure.

## Scope

Create `apps/daemon/src/features/remote/{remote-ports,remote-operations,remote-router,access-store}.ts` and tests; move `daemonInfo`, `accessStatus`, issue/revoke pairing, and client revoke behavior; preserve PRO protocol header behavior.

## Non-goals

Do not move LAN/Tailnet/Funnel listeners (REM-002), client endpoint selection, secure-store UI, or session transport implementation.

## Target ownership and public surface

Remote ports separate identity, access grants, admin authentication, and session revocation. Operations expose typed pairing invalid/expired/not-found/current-admin failures; pairing URLs are validated structurally before grant creation; revocation awaits session invalidation when current behavior requires it.

## Behavior to preserve

Preserve access-file mode/atomic/corrupt behavior, one-time grants/rate limits, constant-time admin checks, pairing link shape, protocol version in daemonInfo, and safe ERR responses.

## Legacy behavior to delete

Delete direct access-store/session/raw TRPCError imports from daemon router and router-local pairing policy.

## Ordered implementation

1. Lock Remote contract/errors/fixtures.
2. Extract ports/adapter and test security boundaries.
3. Bind operations and replace router bodies.
4. Delete direct calls and validate public errors.

## Tests

Test access adapter permissions/corruption, grant issue/exchange/revoke/rate outcomes, operation ordering, router auth/error mapping, and daemonInfo output.

## Forbidden shortcuts

Do not expose token/hash values, use router-local errors, skip revocation ordering, or alter protocol enforcement.

- [ ] Identity/access/pairing/revoke use bound Remote operations and typed errors.
- [ ] Security resilience remains adapter-tested; router direct behavior is gone.
