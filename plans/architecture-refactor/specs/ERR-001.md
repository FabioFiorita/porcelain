# ERR-001 — Define the strict public-error contract and procedure declarations

- Status: Ready
- Batch: 0 — architecture and contract foundations
- Domain: contract errors
- Depends on: `ARC-002`, `CON-011`
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [012](../decisions/012-enforce-the-target-architecture.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Contracts own one strict, composable `PorcelainError` union and every procedure declares its current
intentional expected public codes without changing daemon runtime behavior.

## Why this unit exists

The existing `ProcedureContract` describes input/output/kind but not expected failures. Contract
shape must land independently before daemon mapping, authentication responses, or client adoption.

## Current behavior and evidence

- `packages/contracts/src/procedure-contract.ts` has only `kind`, `input`, and `output`.
- Ten domain `*.procedures.ts` records now cover all 113 names.
- Expected current router refusals are the Remote administrator gate and URL/current-client checks
  in `apps/daemon/src/{trpc,router/daemon}.ts`, plus the destination collision in
  `apps/daemon/src/router/files.ts`.
- Native Git/filesystem/network exceptions remain unexpected until their operation/capability specs
  give them typed meaning; this unit must not guess from messages or native classes.

## Scope

Create `packages/contracts/src/errors/{define-public-error,system-errors,public-errors,fixtures,index}.ts`,
extend `ProcedureContract`, update all ten domain procedure records, export the error contract from
the package root, and add contract/procedure declaration tests. Do not edit any app.

## Non-goals

Do not add request IDs to daemon context, create a formatter, change HTTP bodies/statuses, replace
router throws, parse errors in clients, or classify currently unmodeled native failures.

## Target ownership and public surface

Define strict members with exact literal code/category/retryability plus `message: string`, UUID
`requestId`, and code-owned details:

- `request.invalid` → `invalid-request`, not retryable, no details.
- `auth.unauthenticated` → `unauthenticated`, not retryable, no details.
- `auth.forbidden` → `forbidden`, not retryable, no details.
- `resource.not-found` → `not-found`, not retryable, no details.
- `state.conflict` → `conflict`, not retryable, no details.
- `resource.unavailable` → `unavailable`, retryable, no details.
- `internal.unexpected` → `internal`, not retryable, no details.
- `protocol.update-required` → `conflict`, not retryable, required strict details
  `{ expected: nonnegative integer; received: nonnegative integer | null }`; null means missing or
  unparseable and permits `PRO-004` to represent every rejected header without echoing raw input.

`publicErrorSchema` is a discriminated union on `code`; export `PorcelainError`, `PublicErrorCode`,
the member schemas, category schema, and synthetic fixtures. `definePublicError` accepts literal
code/category/retryability and either no-details or one exact details schema; it never accepts an
arbitrary record.

Add `readonly errors: readonly PublicErrorCode[]` to `ProcedureContract`. Declare:

- `auth.forbidden` on the ten administrator procedures: `accessStatus`, `issuePairingLink`,
  `revokePairingLink`, `revokeAuthorizedClient`, `tailnetStatus`, `setTailnetBind`, `lanStatus`,
  `setLanBind`, `funnelStatus`, and `setFunnelBind`.
- `request.invalid` additionally on `issuePairingLink`.
- `auth.forbidden` on public `revokeCurrentClient`.
- `state.conflict` on `renamePath`.
- `[]` on every other procedure.

Transport authentication, malformed Zod input, and unexpected defects use system errors at the
boundary but are not repeated in every procedure's intentional expected-error list.

## Behavior to preserve

Preserve all 113 names, kinds, input/output schemas, current runtime errors/statuses, authentication,
and client behavior. Error messages remain safe fallback copy and never become a parsing API.

## Legacy behavior to delete

Delete only the contract's inability to express expected public errors. Keep all raw runtime error
construction until `ERR-002`; keep empty HTTP error bodies until `ERR-003`.

## Ordered implementation

1. Build the strict member factory, eight schemas, discriminated union, inferred types, and fixtures.
2. Extend `ProcedureContract.errors` and add an explicit immutable array to every one of the 113
   procedure entries; do not derive codes from names or kinds.
3. Add tests that lock every member's code/category/retryability/details and reject extra, missing,
   malformed, non-UUID, or wrong-details values.
4. Add a declaration test locking the exact non-empty procedure lists above and proving all other
   procedures declare `[]`.
5. Export errors from `packages/contracts/src/index.ts` without changing the horizontal catalog.

## Tests

Add `packages/contracts/src/errors/public-errors.test.ts` and extend procedure catalog/ledger tests
to prove all 113 entries have an errors array and only the named procedures expose non-empty lists.
Test `received` as an integer and null, strict detail ownership, fixed retryability, and synthetic
UUID fixtures.

## Forbidden shortcuts

Do not use `z.any`, `z.unknown`, arbitrary details, string-enum-only errors, inferred retryability,
raw native messages, app imports, or speculative procedure codes. Do not change runtime behavior.

## Completion criteria

- [ ] Eight strict public-error members compose one exported discriminated union.
- [ ] All 113 procedure records explicitly declare errors; only the exact named procedures are
      non-empty.
- [ ] Contract/declaration tests, procedure lint, repository lint, full verify, and diff check pass.
- [ ] One commit lands only `ERR-001`, marks recipe/catalog Landed, leaves a clean worktree, provides
      the README review packet, and finishes without pushing.

## Handoff

members and procedure declarations through the same union.
