# TRM-006 — Complete Terminal request/response cutover and stream gate

- Status: Draft

- Domain: terminal
- Depends on: `TRM-005` (Draft), `TRM-002` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [012](../decisions/012-enforce-the-target-architecture.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Finish Terminal by moving `terminalSessions`/`renameTerminal` and both clients to canonical Terminal paths, then enforce no legacy stream/client descriptor remains.

## Why this unit exists

TRM-002 cut over daemon stream state and TRM-003–005 adapters, but old tRPC roster/rename models and mobile/Web duplicate descriptors remain completion debt.

## Current behavior and evidence

`router/terminal.ts` currently reads `listTerminals`/`renameTerminal`; Web stores/hooks and mobile `lib/daemon/{terminal,procedures/terminal}.ts` retain local stream/roster shapes.

## Scope

Bind roster/rename to TRM-002 Terminal operations, move client calls to contracts/client-runtime adapters, delete local terminal procedure/schema/session mirrors, and add terminal completed-domain gate checks.

## Non-goals

Do not change PTY policy, Actions workflow, Ghostty/native rendering, or add protocol compatibility.

## Target ownership and public surface

The Terminal contract owns roster/rename wire values; client-runtime owns identities/stream semantics; application adapters own platform transport/rendering only.

## Behavior to preserve

Preserve daemon roster hydration, rename behavior, reconnect/reattach/scrollback, output order, and all session limits.

## Legacy behavior to delete

Delete local terminal schemas/procedure descriptors, old Web/mobile terminal session mirrors, and terminal-specific compatibility frames/imports.

## Ordered implementation

1. Verify TRM target client adapters are live.
2. Bind roster/rename operations and migrate callers.
3. Delete descriptors/mirrors and add zero-import gates.

## Tests

Run daemon roster/router, client-runtime stream, Web Ghostty adapter, and mobile native adapter tests.

## Forbidden shortcuts

Do not retain local wire schemas, reintroduce socket wrappers, or merge Terminal events into change notifications.

## Completion criteria

- [ ] Terminal public and stream semantics have canonical owners only.
- [ ] Legacy mirrors/imports are absent and target tests/gates pass.

## Handoff

Terminal is complete.
