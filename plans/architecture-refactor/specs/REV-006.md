- Primary exemplar: no

## Objective

Client-runtime owns the remaining canonical Review identities, mutation effects and `review.changed` consequences; comments remain the RVC-002 submodule.

## Why this unit exists

Web and mobile Review hooks independently define Feature/Review cache names and event invalidation sets for lifecycle, reading, intent, marks, inbox and Evidence.

## Current behavior and evidence

Current reads include active/archive/view/reading/intent/evidence/assets/comments/marks/inbox/explore/layers; writes include lifecycle, intent, reviewed marks, publish/archive and comment actions.

## Scope

Add `packages/client-runtime/src/review/{review-queries,review-mutations,review-notifications,index}.ts`, tests and `./review` export; do not change RVC comment runtime files.

## Non-goals

Do not render canvas/documents, move daemon operations/storage/CLI, recreate comment optimism, or place Review Query data in stores.

## Target ownership and public surface

Export project-scoped identities for active/archive list, view, reading, intent, reviewed paths, inbox, explore, evidence documents/assets/asset and publish cost. `reviewMutations` declares exact authoritative effects for lifecycle/intent/marks/publish/archive operations; no Review mutation is optimistic except RVC comments. `reviewNotificationEffects(review.changed)` returns the exhaustive affected Review identities for its project; it has no raw event branch.

## Behavior to preserve

Keep active/archive separation, Intent/Execution/Evidence topology, viewer reading, evidence caps/assets, marks, inbox, agent refresh, typed errors and comments’ separate reversible behavior.

## Legacy behavior to delete

Delete no app hook here; REV-007/008/009 own Feature aliases, local schemas and presentation cutovers.

## Ordered implementation

1. Verify REV-001 through REV-005, RVC-004 and RT-005.
2. Define identities/effects directly from canonical descriptors and typed notification.
3. Add exhaustive direct tests using contract fixtures.

## Tests

Test project/id/path identity dimensions, every mutation consequence, notification exhaustiveness, public expected failures and isolation from RVC comment transitions.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../../packages/client-runtime/src/review`.
- Run `pnpm lint`.
- Run `rg -n "react|QueryClient|AppEvent|feature-view|FEATURE_|reviewComments" packages/client-runtime/src/review`; it returns no result.

## Forbidden shortcuts

Do not broad-invalidate, include comment reconciliation, import daemon models, or encode rendering/canvas state in runtime.

## Completion criteria

- [ ] Remaining Review reads/writes/notifications have exhaustive shared semantics.
- [ ] Comment ownership remains RVC-specific and direct tests pass.
- [ ] Lint/search pass; the unit is committed.

## Handoff

REV-007 and REV-008 bind this boundary to Web and mobile presentation.
