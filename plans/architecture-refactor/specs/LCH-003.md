## Objective

Produce final launch evidence from a clean checkout: full verify, named critical browser wiring, Terminal stream/reconnect, and Desktop packaging/one-daemon proof.

## Why this unit exists

Passing unit tests do not prove the assembled client, daemon, CLI/watcher, Terminal, and packaged Desktop boundaries. Conversely, broad UI E2E is not launch evidence after E2E-001 relocation.

- E2E-001 defines the retained browser critical wiring suite.
- SUP-003 names Desktop lifecycle, URL, preload, package/native dependency, and one-daemon proof; native Electron evidence is macOS-local.

## Ordered implementation

1. Create a clean checkout/worktree and install dependencies without reusing user project/userData fixtures.
2. Run `pnpm verify` and save full output.
3. Run `pnpm --dir apps/desktop test:e2e -- --project=browser apps/desktop/e2e/critical-wiring.spec.ts`; save traces/screenshots/results.
4. Run SUP-003 focused Desktop tests and `pnpm build`; record one-daemon lifecycle, safe URL, preload boundary, renderer/daemon artifact, and native dependency assertions.
5. In a macOS environment, run `pnpm --dir apps/desktop test:e2e:native` and packaging smoke per Releasing/packaging procedure; otherwise record native proof as environment-not-run, never pass it by inference.
6. Confirm all evidence references isolated dev roots and contains no token/plain secret.
