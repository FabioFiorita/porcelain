# GIT-007 — Delete Review/settings router leakage and complete Git ownership

- Status: Draft
- Batch: 3 — remaining domain cutovers
- Domain: git
- Depends on: `GIT-006` (Draft), `GIT-005` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [012](../decisions/012-enforce-the-target-architecture.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Remove Git procedure ownership from Review/settings routers and all crossed Git compatibility imports.

## Why this unit exists

`diffReading` is currently in `router/review.ts`, `commitModels` in `router/settings.ts`, and Git flow helpers are Review-located despite Decision 013 Git ownership.

## Current behavior and evidence

The backend inventory assigns `diffReading` and `commitModels` to Git and records their current router/helper sources; GIT-006 supplies canonical Git reads/client paths.

## Scope

Move final implementations/imports to `apps/daemon/src/features/git`, delete Git procedures from `router/review.ts` and `router/settings.ts`, and remove crossed contract/client aliases.

## Non-goals

Do not alter Review comments/evidence/inbox, Project Data settings presentation, public procedure names, or Git semantics.

## Target ownership and public surface

The Git router alone binds all Git procedure records; `diffReading` uses narrow Review reading-flow capability only if required by its established GIT-006 operation, never Review router ownership.

## Behavior to preserve

Preserve Changes/History outputs, commit model ordering, cache behavior, errors, and client query identities.

## Legacy behavior to delete

Delete `diffReading` and `commitModels` procedure definitions/imports from Review/settings routers and all `feature`/settings Git re-exports.

## Ordered implementation

1. Verify GIT-006 target caller coverage.
2. Move final router bindings to Git.
3. Delete crossed definitions/imports and enforce zero-import searches.

## Tests

Run Git reading/model router and client-runtime tests, plus architecture dependency checks.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../daemon/src/features/git/git-router.test.ts ../../packages/client-runtime/src/git/git-queries.test.ts
pnpm lint
rg -n "diffReading|commitModels" apps/daemon/src/router/review.ts apps/daemon/src/router/settings.ts
git diff --check
```

## Forbidden shortcuts

Do not leave forwarding procedures or make Review/settings a Git façade.

## Completion criteria

- [ ] Git procedures occur only in canonical Git paths.
- [ ] Crossed router definitions/imports are gone and tests/gates pass.

## Handoff

Git is complete; Review/settings may not regain Git transport ownership.
