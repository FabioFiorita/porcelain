# CON-010 — Move Terminal request/response schemas into the Terminal contract module

- Status: Ready
- Batch: 0 — architecture and contract foundations
- Domain: `terminal`
- Depends on: `CON-009` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Terminal owns exact schemas/kinds for `terminalSessions` and `renameTerminal`; ledger count falls from
8 to 6.

## Why this unit exists

Terminal roster/rename are tRPC while lifecycle frames are WS; both need one Terminal vocabulary.

## Current behavior and evidence

`apps/daemon/src/router/terminal.ts` declares both names. Its authoritative return type and rename
behavior are in `apps/daemon/src/terminal/terminal-manager.ts`. The temporary wire schema is
`terminalInfoSchema` in `packages/contracts/src/procedures/refined.ts`; the duplicate mobile schema
in `apps/mobile/src/lib/daemon/procedures/terminal.ts` is evidence only and is not changed here.

## Scope

Create
`packages/contracts/src/terminal/{terminal.contract,terminal.fixtures,terminal.procedures,index}.ts`,
its tests, and remove exactly the two Terminal entries from the ledger. Do not edit the daemon,
clients, WS contracts, terminal manager, horizontal fallback, or Actions module.

## Non-goals

Do not move stream frames (`RT-001`), PTY logic, Actions, client adapters or terminal recovery.

## Target ownership and public surface

`terminalProcedures` declares:

- `terminalSessions`: input `void`; output an array of strict
  `{ id: string; name: string; cwd: string; status: running | exited; exitCode?: number;
  createdAt: number }` values.
- `renameTerminal`: strict input `{ id: string; name: string }`; output `void`.

Export schemas, inferred wire types, and the kind-aware record through the Terminal public entry
point, following the landed Board/Actions convention rather than importing daemon types.

## Behavior to preserve

Preserve running/exited state, optional numeric exit code, and `createdAt = 0` parsing default from
the current horizontal contract. Preserve unbounded ID/name/cwd strings: rename accepts empty and
whitespace-only names at the wire boundary because `renameTerminal` trims and ignores them inside
the manager. This contract migration must not silently add a non-empty input constraint.

## Legacy behavior to delete

Delete only two Terminal ledger entries; old catalog deletion is `CON-012`.

## Ordered implementation

1. Read the router, manager return type, refined schema, mobile duplicate, baseline, and landed
   domain-procedure exemplars.
2. Define strict TerminalInfo and rename schemas plus fixtures without importing runtime code.
3. Export both kind-aware records and inferred types from the Terminal entry point.
4. Remove only the Terminal ledger entries and update ledger tests from 8 to 6 remaining names,
   all owned by Project Data (3 queries and 3 mutations).

## Tests

Add valid/invalid fixtures for both records, strict unknown-field rejection, running/exited values,
present/absent exit code, createdAt defaulting, unbounded rename strings, `void` output, exact names
and kinds, and exact two-name ledger removal.
