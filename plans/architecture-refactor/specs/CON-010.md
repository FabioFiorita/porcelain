# CON-010 — Move Terminal request/response schemas into the Terminal contract module

- Status: Draft
- Batch: 0 — architecture and contract foundations
- Domain: `terminal`
- Depends on: `CON-009` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Terminal owns exact schemas/kinds for `terminalSessions` and `renameTerminal`; ledger count falls from
8 to 6.

## Why this unit exists

Terminal roster/rename are tRPC while lifecycle frames are WS; both need one Terminal vocabulary.

## Current behavior and evidence

`apps/daemon/src/router/terminal.ts` declares these names; `terminalInfoSchema` is horizontal today.

## Scope

Create `packages/contracts/src/terminal/{terminal.contract,terminal.procedures,index}.ts`, tests and ledger removal.

## Non-goals

Do not move stream frames (`RT-001`), PTY logic, Actions, client adapters or terminal recovery.

## Target ownership and public surface

`terminalProcedures` declares `terminalSessions` query and `renameTerminal` mutation.
`terminal.contract.ts` owns strict terminal info/name schemas and inferred types.

## Behavior to preserve

Preserve running/exited state, optional exit code, createdAt default and name input shape.

## Legacy behavior to delete

Delete only two Terminal ledger entries; old catalog deletion is `CON-012`.

## Ordered implementation

1. Move Terminal info/name schemas to Terminal contract.
2. Export both kind-aware records.
3. Remove ledger items and expect 6 unmigrated names.

## Tests

Add valid/invalid roster and rename fixtures.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/terminal/terminal.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not include Actions or stream schemas in this record.

## Completion criteria

- [ ] Two exact Terminal records exist and ledger count is 6.
- [ ] Tests, lint script and diff check pass.

## Handoff
