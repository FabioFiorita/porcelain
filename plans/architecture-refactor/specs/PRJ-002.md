# PRJ-002 — Define shared Project identities and selection adapters

- Primary exemplar: no

## Objective

Project reads and open/remove effects have typed shared identities while Web and mobile keep only selected-project presentation state.

## Why this unit exists

Web `use-repo.ts`/`stores/repo.ts` and mobile shell `use-workspace.ts` each couple selection to local repo/workspace procedure and cache names.

## Current behavior and evidence

- Current procedures are `recentRepos`, `openRepoPath`, `removeRecentRepo`, and `browseDirs`.
- Web Shell owns project switcher/picker; mobile Shell owns project sheet/picker and route transitions.

## Scope

Add `packages/client-runtime/src/projects/{project-queries,project-mutations,project-notifications,index}.ts`; create Web/mobile `features/projects/project-data.ts` adapters; update project switcher/picker callers only.

## Non-goals

Do not rename every historical repo/workspace surface, move Files/Git state, persist server lists in stores, or change daemon project operations.

## Target ownership and public surface

- Runtime exports `recentProjectsQuery()`, `projectDirectoriesQuery(input)`, `openProject`, and `removeRecentProject`.
- Open affects recent-projects plus the active Project selection boundary; remove affects recent-projects and clears selection only when its path is selected. Neither mutation is optimistic.
- Web/mobile adapters export `useRecentProjects`, `useOpenProject`, `useRemoveRecentProject`, `useProjectDirectories`, and `useSelectedProject`; active selection stores contain only `ProjectSummary | null` and no query list.

## Behavior to preserve

Keep open/browse validation, recent ordering, selected project restoration, sheet/dialog copy, navigation transitions and typed public failures.

## Legacy behavior to delete

Delete direct project procedure/cache-name use from the named adapters; PRJ-003 owns remaining product-boundary aliases.

## Ordered implementation

1. Verify PRJ-001 contracts and operations plus TST-001.
2. Add runtime identities/effects and direct tests.
3. Bind Web/mobile selection adapters and move switcher/picker callers.

## Tests

Test exact identities/effects, selected-removal clearing, inactive selection preservation, public failures with the validating mock, and existing picker/sheet visible behavior.

## Forbidden shortcuts

Do not cache projects in Zustand, use a repo/workspace wire alias, or broad-invalidate client state.
