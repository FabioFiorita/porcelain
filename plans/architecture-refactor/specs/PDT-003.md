## Objective

Web and mobile consume the eight Project Data procedures through
`@porcelain/client-runtime/project-data` identities and non-optimistic
mutations plus `features/project-data` adapters; Settings, Files companion,
Changes, and Review publish import those adapters and own no notes /
disposition / layer wire.

## Why this unit exists

Web settings hooks still call `trpc.<proc>.useQuery` and import nothing
from a Project Data feature. Mobile splits local Zod descriptors across
`procedures/{notes,companion,settings}` and leaves notes inside Files.
PDT-002 handed the eight procedures to the daemon feature; PDT-003 is the
client cutover PDT-002 explicitly deferred.
