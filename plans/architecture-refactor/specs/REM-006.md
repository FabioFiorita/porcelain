legacy endpoint/config/client representations, concentrated

## Why this unit exists

REM-001..005 moved host/network procedures, HTTP/CORS/listeners, shared
endpoint/retry/health/error policy, Web adapters, and mobile strict-v1
environments into the five Remote target roots. Leaving Remote
`migrating` lets deleted `router/network`, `stores/config-store`,
version-3 readers, or `DaemonError` classification re-enter without a
completed-domain gate. Remote spans secrets, HTTP, listeners,
independently updated clients, and persisted state; Decision 015
requires the resilience proof to stay and the historical
representations to stay gone.

## Behavior to preserve

- Access secrets: v1 `{ version: 1, pairings, clients }` at
  `PORCELAIN_ACCESS_FILE` or `porcelainHomePath('access.json')`;
  SHA-256 hex `secretHash`; plaintext grant never written; `mode: 0o600`;
  15-minute pairing TTL; one-time consume; `timingSafeEqual`; snapshot
  exposes `id` / `label` / timestamps only.
- Pairing HTTP: 8_192 body cap; 12 attempts / 60_000 ms per
  `remoteAddress`; rate limit and cap run before grant exchange;
  exhausted grant → `auth.unauthenticated`.
- CORS: echo the configured origin only; never `*`; unlisted origin
  gets no `access-control-allow-origin`.
- Protocol: `/trpc` authenticates then checks the version header;
  `POST /pair` rate-limits then checks the version header; mismatch →
  `protocol.update-required` (409).
- Listeners: start/stop reconcile; empty pick → `start()` null;
  bind collision → `error() === 'in-use'`; `stop()` clears url/error;
  Funnel start throw does not write `funnelBind`.
- Config: unversioned optional booleans; missing / unparseable /
  schema-invalid → empty `{}` after `config.json.corrupt-*` rename
  (home-channel engine).
- Clients: `orderRemoteEndpoints` (preferred, last-known-good, dedup,
  stale drop; no kind rank); retry 500 → 10_000 with injected jitter;
  six health states; `parsePublicError` only; auth and
  `request.invalid` terminal; protocol mismatch absorbing
  `update-required`; mobile walk continues only on `unreachable`.
- Mobile persist: strict `{ version: 1, … }`; v3 / box / omitted icon /
  malformed → `useEnvironmentsCorrupt` without deleting `INDEX_KEY` or
  token keys.
