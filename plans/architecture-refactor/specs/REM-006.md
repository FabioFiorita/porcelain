## Objective

Prove the completed Remote boundary rejects unsafe/auth-invalid/protocol-invalid inputs, survives real listener/access failures safely, and has no legacy endpoint/config/client representations.

## Why this unit exists

Remote spans secrets, HTTP, listeners, independently updated clients, and persisted state; a completed domain requires concentrated resilience/security evidence rather than compatibility remnants.

## Current behavior and evidence

Access secrets use `access-store.ts`; daemon HTTP uses pairing/auth/CORS/body caps; listener adapters manage Tailnet/LAN/Funnel; mobile previously stores version-3 environments and icon coercion. REM-001–005 supply target contracts/adapters/client paths.

## Scope

Add Remote contract/adapter/HTTP/client integration proof and completed-domain architecture gates; delete exact remaining legacy endpoint/version/icon/mixed-config imports named by REM-005.

## Non-goals

Do not add remote fallback endpoints, migration readers, broad E2E, new listener products, or alter healthy endpoint behavior.

## Target ownership and public surface

Remote accepts only protocol-matched strict endpoint/environment values and version-1 owned persisted shapes. Access/auth rejects invalid/missing/revoked credentials fail closed; listener unavailability is typed; clients parse only contract public errors and use target session recovery.

## Behavior to preserve

Preserve secret redaction/mode, request IDs, pairing one-time/rate limits, CORS, listener cleanup, reconnect recovery, and intentional endpoint defaults.

## Legacy behavior to delete

Delete mobile version-3 environment reader/writer, `box`→`desktop` coercion, missing-icon default coercion, legacy endpoint/config aliases, and all completed-domain gate allowlist entries.

## Ordered implementation

1. Run adversarial contract and adapter cases.
2. Exercise real HTTP/pairing/listener failure boundaries with controlled fakes.
3. Delete remaining historical representations/imports.
4. Add zero-legacy architecture/security checks.

## Tests

Test malformed/version mismatch endpoints, secret redaction, revoked and expired grants, pairing caps/rates, CORS, listener unavailable/start-stop cleanup, corrupt config/access data, and mobile/Web public-error recovery.
