## Accepted decision (binding — Option A)

Human-accepted, binding for this unit:

1. All **eight** host-filesystem procedures carry explicit **`projectPath`** on the wire.
2. All file target fields (`path`, `from`, `to`) are **project-relative** paths — **never** daemon-host absolute paths.
3. **Clean atomic cutover** (Decision 015): no absolute-path fallback, dual wire, compatibility alias, ambient project identity (session/recents/root registry), or “try relative then absolute.”
4. **`WorkspaceFiles`** enforces **realpath / symlink containment** under the **caller-nominated** `projectPath` (operation scope / correctness boundary — **not** repository authorization).
5. **Web and mobile callers of the eight** are updated **in this same unit** so `main` never has stranded callers.

This unit **amends contracts** (schemas + public errors + fixtures + procedure `errors` arrays) **in the same commit** as operations/router/client cutover, enforcer registration, audit-doc truth, and helper hardening. FIL-001 locked soft FileView / null preview and declared `files.already-exists` (mapping deferred); this unit **extends** that surface and maps every declared code.

## Trust model (caller-nominated root — binding prose)

Reconcile Option A with `docs/internals/audit/network-boundary.md` §(6):

- A bearer credential remains the **user boundary**. Possession grants host-level capability: the holder may nominate **any** absolute directory as `projectPath`, including **`/`**.
- `projectPath` is a **caller-nominated operation scope / correctness boundary**, not a trusted repository authorization grant, not a recents/session lookup, and not a root registry.
- There is **no** daemon-side “is this a known repo?” check for these eight procedures.
- Public code `files.path-outside-project` means: the target is **outside the request-declared root** (containment failed relative to this request’s `projectPath`). Category is **`invalid-request`** (runtime containment invalidates the request relative to its declared scope) — **not** `forbidden` authorization denial.
- Do **not** claim or document “repo authorization,” “project ACL,” or “only opened repos may be read.”
- Full-host token authority is **preserved**. Contained relative targets under a caller-chosen root are a **correctness/safety shape** for ordinary product flows; a credential holder who sets `projectPath: '/'` retains broad host access by design.

### Contracts — projectPath schema (exact)

In `packages/contracts/src/files/files.contract.ts`:

```ts
/**
 * Caller-nominated operation root for Files host-fs procedures.
 * POSIX absolute path string for Linux/macOS daemons. Not a repo-authorization grant:
 * any absolute directory the credential holder names is acceptable, including `/`.
 */
export function isFilesProjectPath(value: string): boolean {
  if (value.length < 1 || value.length > 4096) return false
  if (value.includes('\0')) return false
  if (!value.startsWith('/')) return false // relative roots are request.invalid
  if (value.includes('\\')) return false
  return true
}

export const filesProjectPathSchema = z
  .string()
  .min(1)
  .max(4096)
  .refine(isFilesProjectPath, { message: 'invalid files projectPath' })
```

**Accepted:** `'/'`, `'/repo'`, `'/repo/'`, `'/var/tmp/playground'`, `'/synthetic/repo'`.
**Rejected (request.invalid):** `''`, `'repo'`, `'./repo'`, `'~/repo'`, `'C:/repo'`, `'\\server\\share'`, strings containing `\0`, length > 4096.

Trailing slashes are **allowed** on the wire; the adapter `realpath`s the root. Clients **normalize** trailing slashes before string prefix conversion (see Web helper).

### Contracts — project-relative target schema (exact)

```ts
export function isFilesProjectRelativePath(value: string): boolean {
  if (value.length === 0 || value.length > 4096) return false
  if (value.includes('\0')) return false
  if (value.startsWith('/')) return false
  if (value.includes('\\')) return false
  if (/^[A-Za-z]:/.test(value)) return false
  const segments = value.split('/')
  for (const segment of segments) {
    if (segment === '' || segment === '.' || segment === '..') return false
    // Note: segment === '..foo' is VALID (not parent traversal)
  }
  return true
}

export const filesProjectRelativePathSchema = z
  .string()
  .min(1)
  .max(4096)
  .refine(isFilesProjectRelativePath, { message: 'invalid project-relative path' })
```

**Rejected:** `''`, `'.'`, `'..'`, `'foo/../bar'`, `'foo/./bar'`, `'/etc/passwd'`, `'foo//bar'`, `'foo/'`, `'foo\\bar'`, `'C:/foo'`, NUL.
**Accepted:** `'README.md'`, `'src/main.ts'`, `'docs/a b.md'`, `'.gitignore'`, `'.porcelain/board.json'`, **`'..foo'`**, **`'..config'`**, `'dir/..foo/bar'`.

Root itself is not a valid file target (empty relative rejected).

### Resolver result types (exact — `files-ports.ts` / `files-path-resolve.ts`)

```ts
import { relative, resolve, sep, isAbsolute, dirname, basename, join } from 'node:path'
import { realpath, lstat, stat } from 'node:fs/promises'
import type { Stats } from 'node:fs'

/** Shared outside predicate — NEVER use startsWith('..') alone; NEVER string-prefix root checks. */
export function isPathOutsideRoot(rootReal: string, absolute: string): boolean {
  const rel = relative(rootReal, absolute)
  return rel === '..' || rel.startsWith(`..${sep}`) || isAbsolute(rel)
}

export type ProjectRootResolution =
  | { ok: true; projectPathWire: string; projectRootReal: string }
  | { ok: false; reason: 'unusable-project-root' }

/**
 * Existing entry under the declared root.
 * lexicalAbsolute = namespace entry the client named (symlink entry preserved).
 * resolvedAbsolute = realpath of that entry (final symlink followed) — containment proven on this.
 */
export type ContainedExistingPath = {
  relative: string
  lexicalAbsolute: string
  resolvedAbsolute: string
}

/**
 * Destination for create / write / rename-to after containment proof.
 * lexicalAbsolute = namespace path for host I/O (symlink entry preserved).
 * ioAbsolute = authorization evidence only (never the create/write open path when a
 *   distinct lexical entry is intended):
 *   - leafExists true: resolveExisting.resolvedAbsolute (real final target under root)
 *   - leafExists false: deepest contained ancestor realpath + remaining lexical suffix
 * Host I/O for create/write/rename dest ALWAYS uses lexicalAbsolute after ok.
 * Never reconstructed across an unresolved/dangling/outside intermediate symlink.
 */
export type ContainedMissingCapablePath = {
  relative: string
  lexicalAbsolute: string
  /** Resolved authorization target (existing leaf) or reconstructed missing path under a contained ancestor. */
  ioAbsolute: string
  /** True when the final lexical path exists as any directory entry (file/dir/symlink). */
  leafExists: boolean
}

export type ResolveFailure =
  | { code: 'path-outside-project'; path: string }
  | { code: 'not-found'; path: string }

export type ResolveExistingResult =
  | { ok: true; value: ContainedExistingPath }
  | { ok: false; error: ResolveFailure }

export type ResolveMissingCapableResult =
  | { ok: true; value: ContainedMissingCapablePath }
  | { ok: false; error: ResolveFailure }
```

### Containment algorithm (exact — adapter only)

Platform: **Linux and macOS** Node daemon. No Windows junctions.

One coherent classified resolver. **No** early `not-found` before ancestor classification.
**No** string-prefix root checks. **No** `startsWith('..')` outside predicate (use `isPathOutsideRoot`).

```text
resolveProjectRoot(projectPathWire) → ProjectRootResolution:
  // Contract already guaranteed POSIX absolute + non-NUL + bounds.
  try:
    projectRootReal = await realpath(projectPathWire)
  catch any:  // including ENOENT, ENOTDIR, ELOOP on the root itself
    return { ok: false, reason: 'unusable-project-root' }
  try:
    st = await stat(projectRootReal)
  catch any:
    return { ok: false, reason: 'unusable-project-root' }
  if !st.isDirectory():
    return { ok: false, reason: 'unusable-project-root' }
  return { ok: true, projectPathWire, projectRootReal }

// Adapter maps unusable-project-root by throwing Error (not a public Files code)
// → ERR boundary → internal.unexpected.
// Tests: nonexistent path; regular file path; root ELOOP (if constructible) → throw.
// Project-root ELOOP is unusable root / internal — NOT files.path-outside-project.

  if isPathOutsideRoot(projectRootReal, absolute) OR relative(projectRootReal, absolute) === '':

    return outside

// Shared ancestor classifier (used by resolveExisting on missing leaf AND by
// resolveMissingCapable reconstruction). Starts at dirname(subject) and climbs.
// ---------------------------------------------------------------------------
//

//   candidate = startCandidate

//     // Climbed past the declared root with no outside/unresolved/loop link under it.
//     if candidate !== projectRootReal AND isPathOutsideRoot(projectRootReal, candidate):
//       return { kind: 'not-found' }
//
//     try:
//       candidateReal = await realpath(candidate)
//       // Successful realpath: exact containment check (no string-prefix).
//       if isPathOutsideRoot(projectRootReal, candidateReal):
//         return { kind: 'path-outside' }   // resolvable intermediate → outside
//       return { kind: 'contained-ancestor', ancestorLexical: candidate, ancestorReal: candidateReal }
//         // chain contained — leaf missing under a proven-inside ancestor; stop climbing
//
//     catch err where err.code === 'ELOOP':
//       return { kind: 'path-outside' }   // intermediate (or looped) symlink cycle
//
//     catch err where err.code === 'ENOENT':

//       // try, where its own catch could mistake it for lstat ENOENT.
//       cl = null
//       try:

//         throw new Error('realpath ENOENT with present non-symlink ancestor')

//       if candidate === projectRootReal:
//         return { kind: 'not-found' }
//       candidate = dirname(candidate)
//       continue
//
//     catch other realpath errors: throw
//

// on the chain. This makes missing read/preview under `root/link → /outside/...`
// path-outside, not soft missing.

  lexicalAbsolute = joinLexical(...)
  if outside → { error: path-outside-project, path: relativePath }

  try:
    resolvedAbsolute = await realpath(lexicalAbsolute)
  catch err:
    if err.code === 'ELOOP':
      // Final or intermediate symlink loop during target resolution
      → { error: path-outside-project, path: relativePath }
    if err.code !== 'ENOENT':
      throw err

    // realpath ENOENT: distinguish final dangling vs true absence vs outside chain
    lst = null
    try:
      lst = await lstat(lexicalAbsolute)
    catch lstatErr:
      if lstatErr.code !== 'ENOENT': throw lstatErr
    if lst !== null:
      if lst.isSymbolicLink():
        // Final dangling symlink — containment unproven
        → { error: path-outside-project, path: relativePath }
      throw new Error('realpath ENOENT with present non-symlink target')
    // lstat ENOENT: MUST inspect ancestors BEFORE returning not-found
    classification = classifyAncestors(projectRootReal, dirname(lexicalAbsolute), relativePath)
    if classification.kind === 'path-outside':
      → { error: path-outside-project, path: relativePath }
    // contained-ancestor or not-found → soft/mutation not-found (leaf truly absent under contained chain)
    → { error: not-found, path: relativePath }

  // realpath(lexicalAbsolute) succeeded (final + intermediate symlinks followed when resolvable)
  if isPathOutsideRoot(projectRootReal, resolvedAbsolute)
     OR relative(projectRootReal, resolvedAbsolute) === '':
    → { error: path-outside-project, path: relativePath }
  return { relative, lexicalAbsolute, resolvedAbsolute }

resolveMissingCapable(projectRootReal, relativePath) → ResolveMissingCapableResult:
  lexicalAbsolute = joinLexical(...)
  if outside → path-outside-project

  // Leaf present as ANY directory entry type (file, dir, or symlink)?
  try:
    lst = await lstat(lexicalAbsolute)
  catch lstatErr:
    if lstatErr.code !== 'ENOENT': throw lstatErr
    lst = null

  if lst !== null:
    // ALWAYS call resolveExisting for real containment — NOT only when the leaf is a symlink.
    // Closes existing non-symlink leaves reached through outside intermediate symlinks
    // (e.g. root/link→/outside/file.txt): joinLexical alone is insufficient.
    existing = resolveExisting(projectRootReal, relativePath)
    if !existing.ok → return that error  // path-outside or not-found
    return {
      relative,
      lexicalAbsolute,                          // namespace I/O path
      ioAbsolute: existing.value.resolvedAbsolute, // authorization evidence only
      leafExists: true,
    }

  // Leaf absent: nearest-existing-ancestor walk with the SAME classified rules.
  // segmentsUnderAncestor: basenames from the first missing component down to the leaf,
  // in order from ancestor-child toward leaf.
  segmentsUnderAncestor = [basename(lexicalAbsolute)]
  candidate = dirname(lexicalAbsolute)

  loop:
    // Climbed past declared root → not-found (no outside/unresolved link under root)
    if candidate !== projectRootReal AND isPathOutsideRoot(projectRootReal, candidate):
      → not-found

    try:
      ancestorReal = await realpath(candidate)
    catch err:
      if err.code === 'ELOOP':
        → path-outside-project
      if err.code !== 'ENOENT':
        throw err
      // candidate missing or dangling
      cl = null
      try:
        cl = await lstat(candidate)
      catch l2:
        if l2.code !== 'ENOENT': throw l2
      if cl !== null:
        if cl.isSymbolicLink():
          → path-outside-project  // intermediate dangling — fail closed
        throw new Error('realpath ENOENT with present non-symlink ancestor')
      // truly missing component — climb
      if candidate === projectRootReal:
        → not-found
      segmentsUnderAncestor.unshift(basename(candidate))
      candidate = dirname(candidate)
      continue

    // realpath(candidate) succeeded — exact containment (no string-prefix)
    if isPathOutsideRoot(projectRootReal, ancestorReal):
      → path-outside-project  // resolvable intermediate → outside (e.g. link → /outside)
    // contained ancestor: reconstruct remaining lexical suffix under ancestorReal
    ioAbsolute = ancestorReal
    for (const seg of segmentsUnderAncestor):
      ioAbsolute = resolve(ioAbsolute, seg)
    if isPathOutsideRoot(projectRootReal, ioAbsolute)
       OR relative(projectRootReal, ioAbsolute) === '':
      → path-outside-project
    return { relative, lexicalAbsolute, ioAbsolute, leafExists: false }
```

**Hardlinks:** path-based containment only; shared outside inode is out of scope (document in adapter tests).
**TOCTOU:** check immediately before I/O; no unbounded retry except the exact duplicate policy below.
**String-prefix containment is forbidden.**

### Rename / duplicate no-clobber (exact — no false atomic promises)

**Rename (preserve best-effort; correct prose):**

1. After both sides resolve, if wire `from !== to` and **`entryExists(to.lexicalAbsolute)`** (any directory entry including a dangling symlink — **not** raw `existsSync`), return `{ code: 'destination-exists' }` **without** calling `rename`.
2. Same-path rename (`from === to` string) skips the conflict precheck (today’s `to !== from` guard).
3. Call `rename(from.lexicalAbsolute, to.lexicalAbsolute)`.
4. **POSIX limitation (document in adapter comment + tests):** Node does not provide portable atomic no-replace rename. A race can still overwrite between precheck and `rename`. Do **not** claim “never overwrite.”
5. Post-`rename` native errors:
   - `ENOENT`: recheck with `lstat`/`stat`:
     - if `from.lexicalAbsolute` missing → `{ code: 'not-found', path: fromRelative }`
     - else if `dirname(to.lexicalAbsolute)` missing → `{ code: 'not-found', path: toRelative }`
     - else **throw** (unexpected race / platform anomaly)
   - `EEXIST` (rare on Linux file-file rename): return `{ code: 'destination-exists' }`
   - other codes: throw

**Duplicate:**

1. `MAX_DUPLICATE_CP_ATTEMPTS = 32`.
2. **`entryExists` (synchronous directory-entry probe)** — do **not** pass `existsSync` into `uniqueDuplicatePath`. Node `existsSync` is **false for dangling symlinks**, so a collision on a dangling sibling would reselect the same occupied name forever (or until the pure-name cap). Exact helper (in `unique-duplicate-path.ts` or adapter-local, used by both pure naming and tests):

```ts
import { lstatSync } from 'node:fs'

/** True when any directory entry exists at path, including a dangling symlink. */
export function entryExists(path: string): boolean {
  try {
    lstatSync(path)
    return true
  } catch (err) {
    const code = (err as NodeJS.ErrnoException).code
    if (code === 'ENOENT') return false
    throw err
  }
}
```

3. Derive **`isDir = (await stat(source.resolvedAbsolute)).isDirectory()`** before naming. This preserves current follow-the-contained-target naming for a symlink to a directory while `cp` still acts on `source.lexicalAbsolute` (the entry). `ENOENT` from this post-resolution `stat` maps to `files.not-found(source input.path)`; other errors throw. Then call pure `uniqueDuplicatePath(lexicalSource, isDir, entryExists)` — **bound** internal loop to `n = 1..10_000`; if none free, throw (→ unexpected). The `exists` callback is `entryExists` (or a test fake with the same semantics: dangling symlink counts as occupied).
4. For attempt `1..MAX_DUPLICATE_CP_ATTEMPTS`:
   - dest = `uniqueDuplicatePath(source.lexicalAbsolute, isDir, entryExists)`
   - verify `joinLexical` containment for dest relative path derived via `relative(projectRootReal, dest)`; if outside → path-outside-project (should not happen for sibling names)
   - `await cp(source.lexicalAbsolute, dest, { recursive: isDir, force: false, errorOnExist: true })`
   - on success: return `relative(projectRootReal, dest)` (POSIX relative string)
   - on `ERR_FS_CP_EEXIST` or `EEXIST`: continue loop (reselect next free name via `entryExists`)
   - on `ENOENT`: return `{ code: 'not-found', path: sourceRelative }` (source disappeared)
   - on other errors: throw
5. If all 32 attempts fail with exist collisions: **throw** Error(`duplicatePath: collision retries exhausted`) → `internal.unexpected`.
6. A raced destination is **never** overwritten (`force: false`, `errorOnExist: true`).
7. Required test: sibling name occupied by a **dangling symlink** must advance to `… copy 2` (or the next free), not stick on the dangling name.

```ts
/** Strip trailing slashes except root `/`. */
export function normalizeProjectRoot(projectPath: string): string {
  const trimmed = projectPath.replace(/\/+$/, '')
  return trimmed === '' ? '/' : trimmed
}

/**
 * Convert a daemon-host absolute path to a project-relative wire path.
 * Returns null when outside, equal to root, empty relative, or not a valid
 * filesProjectRelativePath (including embedded .. segments).
 */
export function projectRelativeFromAbsolute(
  projectPath: string,
  absolutePath: string,
): string | null {
  const root = normalizeProjectRoot(projectPath)
  if (absolutePath === root) return null
  const prefix = root === '/' ? '/' : `${root}/`
  if (!absolutePath.startsWith(prefix)) return null
  const rel = absolutePath.slice(prefix.length)
  if (rel === '') return null
  // Reject repeated separators / dot segments without accepting outside paths
  if (!isFilesProjectRelativePath(rel)) return null
  return rel
}

/**
 * Convert project-relative wire path back to UI absolute.
 * Normalized root `/` → `/${relative}` — NEVER `//${relative}`.
 */
export function projectAbsoluteFromRelative(
  projectPath: string,
  relative: string,
```
