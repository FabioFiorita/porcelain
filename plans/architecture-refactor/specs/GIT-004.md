# GIT-004 — Move both workspace clients to shared Git consequences

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: git
- Depends on: GIT-003, TST-001, RT-005
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [008](../decisions/008-give-each-client-state-one-owner.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Web and mobile workspace adapters bind GIT-003’s non-optimistic checkout/create/add-worktree effects and delete broad/string invalidation logic.

## Why this unit exists

The two clients expose the same intent but one broad-flushes every Web cache and the other maintains local arrays under a mobile daemon descriptor module.

## Current behavior and evidence

- Web `hooks/use-worktrees.ts` owns `useCheckout`/`useCreateBranch` and `utils.invalidate()`.
- Mobile `features/shell/use-workspace.ts` imports descriptors/types and `WORKSPACE_CHECKOUT_INVALIDATIONS`/`WORKSPACE_ADD_WORKTREE_INVALIDATIONS` from `lib/daemon/procedures/workspace.ts`.
- Shell branch/worktree sheets and switchers consume their public hooks; RT-005 supplies validated Git change delivery.

## Scope

Create Web `features/git/workspace/` and mobile `features/git/workspace/` adapters with public indexes; move current hook callers; remove the listed Web hook and mobile workspace descriptors/arrays after all callers move.

## Non-goals

Do not relocate Changes/History/Diff, change branch-sheet copy/forms, persist Git Query data in stores, or add optimistic UI.

## Target ownership and public surface

- Web exports `useGitWorkspace`, `useGitCheckout`, `useGitCreateBranch`, and `useGitAddWorktree`; mobile exports the same behavior from its Git workspace feature boundary.
- Each uses canonical Git contract types/descriptors, maps GIT-003 identities to its current Project/environment key, invokes exactly the named mutation consequence, and displays typed public failures.
- Both install the GIT-003 notification adapter once at their domain/session boundary; the typed working-tree fact invalidates only declared identities.

## Behavior to preserve

Keep branch label/refetch behavior, 15-second worktree/inbox polling, destination preview, dirty-tree refusal, current worktree selection, and the strict narrower add-worktree refresh.

## Legacy behavior to delete

Delete `apps/web/src/hooks/use-worktrees.{ts,test.ts}`, `utils.invalidate()` workspace calls, mobile `procedures/workspace.ts` Git descriptor/type exports, both `WORKSPACE_*_INVALIDATIONS`, and direct callers of those paths.

## Ordered implementation

1. Verify GIT-003 and RT-005 are landed.
2. Add both platform adapters over the shared definitions and move branch/worktree switcher/sheet callers.
3. Delete raw hooks/descriptors/arrays, then prove no direct cache flush remains.

## Tests

- Web/mobile adapter tests use TST-001 and prove exact checkout versus add-worktree cache consequences, pending/refused states and project/environment isolation.
- Retain branch-switcher, worktree-switcher, workspace-list and workspace-create-form tests for visible controls and destination copy.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../web/src/features/git/workspace ../mobile/src/features/git/workspace ../web/src/components/git/branch-switcher.test.tsx ../web/src/components/git/worktree-switcher.test.tsx ../mobile/src/features/shell/workspace-lists.test.ts`.
- Run `pnpm --dir apps/mobile typecheck` and `pnpm lint`.
- Run `rg -n "utils\.invalidate\(\)|WORKSPACE_(CHECKOUT|ADD_WORKTREE)_INVALIDATIONS|procedures/workspace|hooks/use-worktrees" apps/web/src apps/mobile/src`; it returns no result.

## Forbidden shortcuts

Do not keep a broad flush, raw notification, local descriptor/schema, or an optimistic Git state patch.

## Completion criteria

- [ ] Both client workspace paths use GIT-003 through feature boundaries.
- [ ] Legacy broad/string paths are deleted and visible behavior is tested.
- [ ] Typecheck, lint and searches pass; the unit is committed.

## Handoff

GIT-005 and GIT-006 may extend the canonical Git feature without restoring workspace aliases.
