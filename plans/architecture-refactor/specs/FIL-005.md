# FIL-005 — Move Web Files and Viewer to the shared boundary

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: files
- Depends on: FIL-004, TST-001, RT-005
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [008](../decisions/008-give-each-client-state-one-owner.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Web Files adapters and the Viewer seam use canonical Files contracts/runtime effects and no raw daemon `DirEntry` or `FileView` model.

## Why this unit exists

`hooks/use-files.ts` mixes transport, invalidation, raw watches, viewer behavior and `@backend/api` types across Shell and Viewer.

## Current behavior and evidence

- Its callers include `components/shell/{file-tree,tree-node,file-commands,pinned-group,files-quick-access}.tsx` and `components/viewer/{file-content,html-view,source-view}.tsx`.
- `useWatchOpenFiles` reads tabs; `useWatchTreeDirs` reads `tree-dirs`; both directly call `lib/daemon.ts` watch functions.
- `useWriteTextFile` refreshes content/preview/Git; structural actions refresh tree/pins/Git; scope actions refresh tree/pins/scope.

## Scope

Create `apps/web/src/features/files/{files-queries,files-mutations,files-notifications,files-interests,index}.ts`; update named Shell/Viewer callers; delete `hooks/use-files.ts` and its raw `@backend/api` imports; retain Shell-only reveal/tabs/dialog stores.

## Non-goals

Do not move generic Viewer rendering/virtualization, Electron `revealInFinder`, Search, Git adapters, path safety, or change visual copy.

## Target ownership and public surface

- `files-queries.ts` exports `useFilesTree`, `usePinnedFiles`, `useFilesScope`, `useFileContent`, `useFilePreview`, and `prefetchFileContent`, mapping active Project/daemon identity to FIL-004 identities and FIL-001 descriptors.
- `files-mutations.ts` exports `useFilesActions` and `useFileScopeActions`, binds all ten FIL-004 effects, returns typed public failures, and never writes cached filesystem data.
- `files-interests.ts` exports `useFilesInterestBridge`, deriving open Viewer paths and `useTreeDirsStore` directories into one RT-005 session interest registration.
- `files-notifications.ts` exports `applyFilesNotification`; `index.ts` is the only Files import surface outside the feature.

## Behavior to preserve

Keep hidden/pinned behavior, directory ordering, file tab closing after successful trash, preview/source separation, visible write failures, shell reveal, and agent/external watch refresh.

## Legacy behavior to delete

Delete `hooks/use-files.ts`, direct `watchFiles`/`watchDirs` use, `@backend/api` Files imports, raw Files app-event handling, and raw tRPC Files procedure calls after callers move.

## Ordered implementation

1. Verify FIL-004 and RT-005 are landed.
2. Add the feature adapters and single interest/notification bridge.
3. Move every named caller to the public entry point, preserve local Shell/Viewer state, then delete the hook and raw paths.

## Tests

- Feature tests use TST-001 to prove keys, disabled reads, write failure, non-optimistic refetch and exact notification effects.
- Interest tests prove tabs/directories produce one deduplicated registration and recovery refetches authoritative data.
- Retain file-tree, HTML/text/source-view and command tests for visible actions and accessibility without mocked feature hooks.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../web/src/features/files ../web/src/components/shell/file-tree.test.tsx ../web/src/components/viewer/html-view.test.tsx ../web/src/components/viewer/text-file-view.test.tsx`.
- Run `pnpm lint`.
- Run `rg -n "@backend/api|trpc\.(readDir|pinnedEntries|repoScope|readFile|previewHtml|writeTextFile|createFile|createFolder|renamePath|duplicatePath|trashPath)|watch(Files|Dirs)|hooks/use-files" apps/web/src`; it returns no result.

## Forbidden shortcuts

Do not retain a raw socket watcher, broad invalidation, local FileView schema, app-specific write effects, or Query data in a Zustand store.

## Completion criteria

- [ ] Web Files and its Viewer seam use contracts/runtime through one feature entry point.
- [ ] Raw daemon types/watchers/hooks are absent and focused behavior tests pass.
- [ ] Lint and deletion search pass; the unit is committed.
