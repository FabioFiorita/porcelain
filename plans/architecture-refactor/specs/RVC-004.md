# RVC-004 — Complete the mobile Review-comment cutover

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: review
- Depends on: RVC-002, RVC-003, TST-001, RT-005
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [008](../decisions/008-give-each-client-state-one-owner.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Mobile comments consume the same contract/runtime semantics as Web and delete Review-local comment descriptors and `COMMENT_INVALIDATIONS`.

## Why this unit exists

`features/comments/use-comments.ts` is an invalidate-only adapter over a duplicate Review procedure module.

## Current behavior and evidence

- It imports five mutations, list query and `ReviewComment` from `lib/daemon/procedures/review.ts` and declares `COMMENT_INVALIDATIONS`.
- `comment-index.ts`, `line-range.ts`, `selection-bar.tsx`, and `comment-composer.tsx` own local presentation/selection behavior.
- Mobile `app-events.ts` currently maps coarse comments; RT-005 deletes it.

## Scope

Replace `features/comments/use-comments.ts` with `comment-data.ts` and `comment-notifications.tsx`; update comment callers; remove only comment descriptors/types from `lib/daemon/procedures/review.ts`; add focused tests.

## Non-goals

Do not move Review canvas, alter selection/range algorithms, persist comment data in a store, or edit non-comment Review descriptors.

## Target ownership and public surface

- `comment-data.ts` exports `useReviewComments`, `useCommentActions`, `useCommentIndex`, `useCommentedLinesByPath`, and `NewComment`, binding RVC-002 identities/effects to the active environment Query cache.
- `comment-notifications.tsx` exports `ReviewCommentNotificationBridge`, mounted once inside the existing mobile session/query tree; validated `review.changed` frames map through RVC-002 and invalidate only matching environment/project keys.
- `comment-index.ts` remains the pure presentation index; `ReviewComment` imports from `@porcelain/contracts/review`.

## Behavior to preserve

Keep newest-first comments, line/file anchors, selection-bar handoff, pending/error exposure, reversible mutation feedback, reconnect freshness, and unpersisted selection state.

## Legacy behavior to delete

Delete `use-comments.ts`, `COMMENT_INVALIDATIONS`, its Review-local imports, and only `reviewComments` plus five comment descriptor/schema/type declarations from the mobile Review procedure module.

## Ordered implementation

1. Verify RVC-001 through RVC-003 and RT-005 are landed.
2. Build the data/notification adapters using RVC-002 and mount one bridge.
3. Change comment components to the feature boundary, delete local descriptors/hooks, and retain pure index/range files.

## Tests

- `comment-data.test.tsx`: active environment/project key, five transitions, rollback/reconcile/refetch and public failure using TST-001.
- `comment-notifications.test.tsx`: matching change invalidates once; other project and malformed frame do not alter the cache.
- Retain `comment-index.test.ts` and `line-range.test.ts`; add presentation assertions for composer/selection actions without hook mocks.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../mobile/src/features/comments ../mobile/src/lib/daemon/procedures/changes.test.ts`.
- Run `pnpm --dir apps/mobile typecheck` and `pnpm lint`.
- Run `rg -n "reviewComments|addReviewComment|editReviewComment|deleteReviewComment|resolveReviewComment|clearResolvedReviewComments|ReviewComment" apps/mobile/src/lib/daemon/procedures/review.ts`; it returns no result.
- Run `rg -n "COMMENT_INVALIDATIONS|procedures/review|app-events" apps/mobile/src/features/comments`; it returns no result.

## Forbidden shortcuts

Do not retain string invalidation, a second socket subscription, a local comment schema, or a store copy of comments.

## Completion criteria

- [ ] Mobile and Web use the same Review-comment semantics and valid mock boundary.
- [ ] The named mobile descriptors and invalidation path are deleted.
- [ ] Tests, typecheck, lint and deletion searches pass; the unit is committed.

## Handoff

Later Review work may rely on a completed comments subdomain without recreating its wire seam.
