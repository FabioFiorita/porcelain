# CON-006 — Move Git procedure schemas into the Git contract module

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: `git`
- Depends on: `CON-005` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Git owns exact schemas/kinds for its 30 current procedures, including `diffReading`; ledger count
falls from 79 to 49.

## Why this unit exists

Git’s wire values are partly refined in a horizontal file and Changes/History reading is misplaced in
the Review router.

## Current behavior and evidence

The exact 30-name list is the Git rows in `../inventory/backend.md`; source routers are
`router/git.ts`, `router/review.ts:diffReading`, and `router/settings.ts:commitModels`.

## Scope

Create `packages/contracts/src/git/{git.contract,git.procedures,index}.ts`, full tests and ledger removal.

## Non-goals

Do not move Review Inbox, change Git behavior, generate errors, extract adapters or alter clients.

## Target ownership and public surface

`gitProcedures` contains the inventory’s 30 names. Query records are every `git*` read plus
`diffReading` and `commitModels`; mutations are quick command, push, stage/unstage/discard, commit,
generation, checkout, create branch and add worktree. `git.contract.ts` owns all strict flow/diff,
status, branch/worktree, commit, suggestion and model schemas.

## Behavior to preserve

Preserve current defaults/limits, discriminated diff/flow values, commit-model options and output
shapes.

## Legacy behavior to delete

Delete only the 30 Git ledger entries; keep horizontal source until `CON-021`.

## Ordered implementation

1. Transcribe all 30 router schemas and currently inferred output objects.
2. Export the kind-aware Git record and its inferred types.
3. Remove ledger entries and expect 49 unmigrated names.

## Tests

Add table fixtures for all 30 pairs; include defaults/maximum limits and every flow/diff discriminator.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/git/git.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not model Git values with unknown/adapter types or move Review Inbox into Git.

## Completion criteria

- [x] All 30 exact Git records and kinds exist.
- [x] Ledger count is 49 and Git entries are absent.
- [x] Tests, lint script and diff check pass.

## Handoff

`GIT-001` and `GIT-005` may consume the Git contract module.
