# CON-005 — Move Search procedure schemas into the Search contract module

- Status: Draft
- Batch: 0 — architecture and contract foundations
- Domain: `search`
- Depends on: `CON-004` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Search owns exact schemas/kinds for `searchText`, `searchCode`, and `searchFiles`; the ledger falls
from 82 to 79 entries.

## Why this unit exists

The three Search intentions are currently in `router/files.ts`, and only file search is refined.

## Current behavior and evidence

`searchText` and `searchCode` use Git-backed inputs; `searchFiles` returns fuzzy file/dir results.

## Scope

Create `packages/contracts/src/search/{search.contract,search.procedures,index}.ts`, tests and ledger removal.

## Non-goals

Do not move router/adapters, Files scope, Git queries, client UI or search suggestions.

## Target ownership and public surface

`searchProcedures` has three `kind: 'query'` records. `search.contract.ts` owns strict text/code
search input/result schemas, including regex/case/include/exclude fields and file/dir result kind.

## Behavior to preserve

Preserve empty/nonempty query rules and current result serialization.

## Legacy behavior to delete

Delete only three Search ledger entries; `CON-012` deletes old catalog files.

## Ordered implementation

1. Translate three router I/O shapes to strict Search Zod schemas.
2. Export `searchProcedures` and types from Search index.
3. Remove ledger entries and expect 79 unmigrated names.

## Tests

Add valid/invalid input/output fixtures for all three records.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/search/search.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not place Search under Files, use Git adapter types or keep unknown output.

## Completion criteria

- [ ] Three exact query records exist.
- [ ] Ledger count is 79 and Search entries are absent.
- [ ] Tests, lint script and diff check pass.

## Handoff

`SEA-001` may use the Search module as its only public wire source.
