# GIT-001 — Define checkout, worktree, status, branch, and worktree contracts

- Status: Draft
- Batch: 2 — focused behavior exemplars
- Domain: git
- Depends on: `CON-021`, `ERR-001` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Make `gitStatus`, `gitBranches`, `gitWorktrees`, `gitCheckout`, and `gitAddWorktree` exact canonical Git contracts with declared expected failures.

## Why this unit exists

Checkout/add-worktree are the multi-query mutation exemplar, but current router values and mobile workspace descriptors duplicate incomplete Git wire shapes.

## Current behavior and evidence

`apps/daemon/src/router/git.ts` directly calls `gitStatus`, `gitBranches`, `gitWorktrees`, `gitCheckout`, and `gitAddWorktree` from `git/git.ts`; mobile mirrors reside in `apps/mobile/src/lib/daemon/procedures/workspace.ts`. The backend inventory classifies all five as Git despite present UI/router placement.

## Scope

Refine only `packages/contracts/src/git/{git.contract,git.procedures}.ts` and tests for those five names, their serializable status/branch/worktree values, and the error declarations consumed by GIT-002.

## Non-goals

Do not move Git process execution, alter current arguments, add checkout optimism, migrate clients, remove mobile descriptors, or change other Git procedures.

## Target ownership and public surface

Strict values own repository status entries, branch identity/current state, worktree path/branch/head state, checkout branch input, and add-worktree branch input/result. Procedure records retain current kinds and declare only intentional `git.not-a-repository`, `git.branch-not-found`, `git.branch-already-exists`, `git.worktree-conflict`, and `git.working-tree-conflict` outcomes. No process stderr or Git object type crosses the wire.

## Behavior to preserve

Preserve current result ordering, relative/absolute wire path choices, branch naming validation already accepted by the router, and no-op/normal Git output shapes.

## Legacy behavior to delete

Delete local schemas/types for these values from router tests and the old contracts fallback; do not delete mobile workspace descriptors until GIT-004.

## Ordered implementation

1. Capture current serialization fixtures from focused Git tests.
2. Make strict Git schemas/error lists the sole procedure values.
3. Replace local daemon type annotations with contract-inferred types only.
4. Add invalid shape/error fixtures and output-parsing proof.

## Tests

Add contract valid/invalid fixtures for status, branch, worktree, checkout, add-worktree, and each declared error; retain Git router serialization assertions.

## Forbidden shortcuts

Do not use `z.unknown`, make stderr public, add a `workspace` contract alias, or change client behavior.

## Completion criteria

- [ ] Five procedures have strict wire schemas, kinds, and exact expected-error lists.
- [ ] No local fallback schema/type owns the five public values.
- [ ] Fixtures, router parsing, lint, and diff check pass.
