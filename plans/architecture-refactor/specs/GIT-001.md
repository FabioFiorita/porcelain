## Objective

Make `gitStatus`, `gitBranches`, `gitWorktrees`, `gitCheckout`, and `gitAddWorktree` exact canonical Git contracts with declared expected failures.

## Why this unit exists

Checkout/add-worktree are the multi-query mutation exemplar, but current router values and mobile workspace descriptors duplicate incomplete Git wire shapes.

## Current behavior and evidence

`apps/daemon/src/router/git.ts` directly calls `gitStatus`, `gitBranches`, `gitWorktrees`, `gitCheckout`, and `gitAddWorktree` from `git/git.ts`; mobile mirrors reside in `apps/mobile/src/lib/daemon/procedures/workspace.ts`. The backend inventory classifies all five as Git despite present UI/router placement.

- `packages/contracts/src/git/git.contract.ts` already owns the strict serializable values and
  current input/output shapes; `packages/contracts/src/git/git.procedures.ts` already owns the
  five procedure records, but each currently declares `errors: []`.
- `packages/contracts/src/errors/public-errors.ts` has no Git members, so the five reviewed codes
  cannot yet be represented by `PublicErrorCode`; `packages/contracts/src/errors/fixtures.ts` is
  exhaustive over that union.
- The landed router seam test is
  `apps/daemon/src/router/git.contract.test.ts`; there is no
  `apps/daemon/src/router/git.test.ts` or `packages/contracts/src/git/git.contract.test.ts`.
- `apps/daemon/src/git/diff.ts` owns internal parser types (`ChangedFile`, `Worktree`) and
  `apps/daemon/src/git/git.ts` owns its internal `BranchRef`; these are domain/adapter models,
  not public wire fallbacks. Decision 005 keeps them internal, so this unit must not replace them
  with contract-inferred types or widen the scope into daemon code.

## Scope

Refine the Git contract boundary only: retain the existing value schemas in
`packages/contracts/src/git/git.contract.ts`, add the Git-owned public-error members in
`packages/contracts/src/git/git.errors.ts`, update `git.procedures.ts`, and update the Git contract
indexes, composed public-error union, exhaustive public-error fixtures, and focused tests. Do not
edit daemon process code, router behavior, mobile descriptors, or the existing five wire shapes.

## Non-goals

Do not move Git process execution, alter current arguments, add checkout optimism, migrate clients, remove mobile descriptors, or change other Git procedures.

## Target ownership and public surface

The existing strict values remain the sole owners of repository status entries, branch identity,
worktree path/branch display labels, checkout branch input, and add-worktree branch input/result.
The worktree `branch` label continues to carry the existing branch, detached-HEAD, or `bare`
display value; do not add a second head field. No process stderr, native Git object, host path, or
daemon parser type crosses the wire.

Add these Git-owned public errors to the composed union. Every member has no details, is not
retryable, and uses the listed category; messages are safe fallback copy only:

| Code | Category | Retryable | Details |
| --- | --- | --- | --- |
| `git.not-a-repository` | `not-found` | no | none |
| `git.branch-not-found` | `not-found` | no | none |
| `git.branch-already-exists` | `conflict` | no | none |
| `git.worktree-conflict` | `conflict` | no | none |
| `git.working-tree-conflict` | `conflict` | no | none |

The five procedure records declare exactly these ordered lists:

| Procedure | Errors |
| --- | --- |
| `gitStatus` | `['git.not-a-repository']` |
| `gitBranches` | `['git.not-a-repository']` |
| `gitWorktrees` | `['git.not-a-repository']` |
| `gitCheckout` | `['git.not-a-repository', 'git.branch-not-found', 'git.working-tree-conflict']` |
| `gitAddWorktree` | `['git.not-a-repository', 'git.branch-already-exists', 'git.worktree-conflict']` |

These are declarations for GIT-002's capability normalization; this unit does not classify native
stderr or change runtime mapping.

## Behavior to preserve

Preserve current result ordering, relative/absolute wire path choices, branch naming validation already accepted by the router, and no-op/normal Git output shapes.

## Legacy behavior to delete

Delete the all-empty error declarations for these five procedures and the absence of Git members
from the public-error union. There is no current daemon/router fallback schema to delete after
CON-016/CON-021, and mobile workspace descriptors remain until GIT-004.

## Ordered implementation

1. Treat the already-landed strict value schemas, current input constraints, and router
   serialization assertions as fixed baselines; do not alter their shapes or daemon-local parser
   types.
2. Add the five no-details Git public-error schemas, export them from the Git/error/package indexes,
   compose them into `publicErrorSchema`, and extend `publicErrorFixtures` exhaustively.
3. Replace the five `errors: []` declarations with the exact ordered lists above and add focused
   declaration/valid-invalid error fixtures.
4. Retain and extend router serialization assertions without spawning Git or changing router code.

## Tests

assertions. Do not reimplement native Git classification in tests.
