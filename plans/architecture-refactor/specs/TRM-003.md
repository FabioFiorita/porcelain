# TRM-003 — Define the shared Terminal stream state machine

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: terminal
- Depends on: TRM-001, TRM-002, RT-003
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Client-runtime owns transport-neutral Terminal attach correlation, epoch/sequence recovery, scrollback ordering, and honest stream-loss state.

## Why this unit exists

Web `lib/daemon.ts` and mobile `lib/daemon/terminal.ts` independently generate request ids, track attachments, correlate replies, replay scrollback, and reattach after reconnect.

## Current behavior and evidence

- Terminal is a socket stream, not Query data; roster is `terminalSessions` and currently polls every five seconds.
- Create/attach/paste replies correlate by `reqId`; attach scrollback precedes subsequent live data; a socket drop rejects in-flight requests.
- RT-003 supplies ready/reconnect/epoch semantics; TRM-001/002 supply canonical frames and daemon lifecycle.

## Scope

Add `packages/client-runtime/src/terminal/{terminal-stream,terminal-requests,terminal-recovery,index}.ts`, direct tests and `./terminal` export. Preserve existing pure key/touch helpers as separate leaves.

## Non-goals

Do not implement WebSocket, React, Ghostty/xterm/native renderer, PTY operations, Query roster hooks, clipboard, or platform input handling.

## Target ownership and public surface

- Export `createTerminalStreamState`, `TerminalStreamState`, `TerminalRequest`, `TerminalStreamEffect`, and `TerminalRecovery`.
- `requestCreate`, `requestAttach`, `requestPasteImage`, and `requestPasteFile` accept an adapter-provided request id and deadline; correlation accepts only matching canonical reply types and rejects on close/deadline.
- `attach(id)` records a desired attachment; `attached` applies scrollback before contiguous data; `data` requires matching epoch and next sequence; `exit` marks the session exited; `detach` and `kill` remove desired attachment.
- Reconnect/epoch change/sequence gap returns explicit `reattach` plus `refresh-roster`; it never invents missed bytes. Mismatch is terminal. Write/resize/kill are emitted only by the platform transport after valid state checks.

## Behavior to preserve

Keep daemon-owned PTY lifetime, per-socket attachment, request timeout, attachment idempotence, scrollback-before-live order, chunk/cap validation, and roster reconciliation after external kill.

## Legacy behavior to delete

Delete no platform module here. TRM-004 and TRM-005 remove their duplicated attachment/correlation/reconnect state.

## Ordered implementation

1. Verify TRM-001, TRM-002 and RT-003 exact frame/ready contracts.
2. Implement request correlation and pure stream state/recovery with injected clock/id/transport outputs.
3. Export the narrow state-machine boundary; do not add a socket or cache import.

## Tests

Prove create/attach/paste correlation, timeout/close rejection, duplicate attach, scrollback before data, contiguous and gap/epoch recovery, stale reply rejection, exit/detach/kill, mismatch terminal state, and no reconstructed bytes.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../../packages/client-runtime/src/terminal`.
- Run `pnpm lint`.
- Run `rg -n "react|WebSocket|QueryClient|zustand|randomUUID|Date\.now|terminal:" packages/client-runtime/src/terminal`; it returns no result.

## Forbidden shortcuts

Do not treat terminal frames as Query notifications, replay guessed writes/creates, use ambient ids/clocks, or expose raw socket events.

## Completion criteria

- [ ] One framework-free state machine owns correlation, attachment and recovery semantics.
- [ ] Direct tests prove stream order and honest loss/recovery behavior.
- [ ] Lint and boundary search pass; the unit is committed.

## Handoff

TRM-004 and TRM-005 bind this state machine to their platform sockets and renderers.
