# RVC-003 — Move Web Review comments to shared semantics

- Status: Draft
- Batch: 2 — focused behavior exemplar
- Domain: review
- Depends on: RVC-002, TST-001, RT-005
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [008](../decisions/008-give-each-client-state-one-owner.md), [009](../decisions/009-treat-realtime-as-recoverable-signals-and-streams.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: yes

## Objective

Web comments use canonical Review contracts, RVC-002 optimism and typed session notifications with no daemon-model import or raw invalidation.

## Why this unit exists

`apps/web/src/hooks/use-comments.ts` owns both the data adapter and all optimism, while comment UI remains under Git and Shell.

## Current behavior and evidence

- `use-comments.ts` imports `ReviewComment` from `@backend/stores/comment-store`, tRPC procedures, `randomId`, and implements five cache mutations.
- Callers are `components/git/{comment-composer,comment-marker,diff-view,reading-surface}.tsx` and `components/shell/comments-group.tsx`.
- `hooks/use-app-events.ts` currently owns the coarse comments branch; RT-005 removes that path.

## Scope

Create `apps/web/src/features/review/comments/{comment-queries,comment-mutations,comment-notifications,comment-index,index}.ts`; move the pure index from the hook; update the named callers; delete `hooks/use-comments.{ts,test.ts}` and its raw event branch.

## Non-goals

Do not rename Review surfaces, move non-comment Git/Review components, alter comment copy/anchors, or change daemon behavior.

## Target ownership and public surface

- `comment-queries.ts` exports `useReviewComments` and `useCommentIndex`; it maps the active Project and daemon identity to `reviewCommentsQuery` and the RVC-001 list descriptor.
- `comment-mutations.ts` exports `useCommentActions` and `NewComment`; it binds all RVC-002 definitions to Web Query, supplies temporary id/time, performs cancel/snapshot/transition/rollback/reconcile/refetch, and exposes typed public failures to existing UI copy.
- `comment-notifications.ts` exports `applyReviewCommentNotification`; it receives RT-005 validated change frames and invalidates only the mapped active-environment comments key.
- `index.ts` is the sole feature import surface; components never import tRPC, QueryClient, `@backend`, or a procedure descriptor.

## Behavior to preserve

Keep markers/range expansion, composer and comments-group controls, immediate reversible feedback, failure visibility, newest-first ordering, and agent-originated refresh.

## Legacy behavior to delete

Delete the old hook/test, its `@backend` type import, manual temporary id/rollback code, and the comments branch from `use-app-events.ts`; retain unrelated branches.

## Ordered implementation

1. Verify RVC-002 and RT-005 are landed.
2. Create the feature adapter/index, port the pure comment index, and bind read/write/notification behavior to contracts/runtime.
3. Move all named component imports to the feature entry point, then delete the old hook and event branch.

## Tests

- Feature query/mutation tests prove active Project key, five optimistic paths, rollback, reconciliation, exact refetch, and typed failure through TST-001’s Web adapter.
- Notification tests prove same-project invalidation and different-project no-op.
- Existing marker/composer/comments-group tests retain visible anchors, actions, pending and recovery behavior without mocking feature hooks.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../web/src/features/review/comments ../web/src/components/git/comment-marker.test.tsx ../web/src/components/shell/comments-group.test.tsx`.
- Run `pnpm lint`.
- Run `rg -n "@backend/stores/comment-store|trpc\.(reviewComments|addReviewComment|editReviewComment|deleteReviewComment|resolveReviewComment|clearResolvedReviewComments)|case 'comments'|hooks/use-comments" apps/web/src`; it returns no result.

## Forbidden shortcuts

Do not keep a Web-only transition, string invalidation, raw session listener, broad invalidate, or component mock.

## Completion criteria

- [ ] Web comment reads, writes and notifications use only contracts/runtime through the feature boundary.
- [ ] Legacy hook/event/type imports are absent and presentation behavior is covered.
- [ ] Focused tests, lint and deletion search pass; the unit is committed.
