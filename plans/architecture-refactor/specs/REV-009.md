## Objective

The live wire is the 23-name canonical Review catalog: `procedureCatalog` composes
109 names, every router, client, and CLI caller binds the canonical vocabulary, both
target files are gone, and no Feature name, `loopEvidence*` name, root-`index.html`
reader, `hasReport`/`legacyReport`/`dir`/`medium` marker, or per-path reviewed mutation
survives anywhere in `apps/` or `packages/` — proved by a banned-identifier gate that
fails the build if any of them regrows.

## Why this unit exists

REV-001 through REV-008 deliberately built the whole canonical Review — contracts,
operations, capabilities, adapters, CLI writers, and three client slices — *behind the
Feature-era wire names*, because renaming the wire while installed clients still call
it would have required a dual wire, which Decision 015 forbids. Every one of those
eight units therefore closed with a recorded debt pointing here, and REV-001 named this
unit "the sole owner of activation". The debts are only payable together: the contract
catalog, the routers, the three clients, and the CLI all name the same procedures, so
renaming any one of them alone breaks `lint-procedure-contracts`' 1:1 gate and the
running product. This is the single commit where the half-migrated state ends.
