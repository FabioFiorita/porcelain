# CON-016 — Bind Git router procedures to canonical contracts

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: Git / Review contract boundary
- Depends on: `CON-015`
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [012](../decisions/012-enforce-the-target-architecture.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

The 28 Git procedures and Review-owned `worktreeInbox` in `router/git.ts` use exact canonical input
and output contracts without changing Git commands, limits, generation, worktree, or inbox behavior.

## Why this unit exists

`git.ts` is the largest command-oriented router and includes one Review read for historical source
layout reasons. It is isolated as one 29-procedure review unit so no concurrent recipe owns the file.

## Current behavior and evidence

The exact Git names are `gitQuickCommand`, `gitPush`, `gitStageAll`, `gitUnstageAll`, `gitStageFile`,
`gitUnstageFile`, `gitDiscardFile`, `gitCommit`, `gitGenerateCommitMessage`,
`gitGenerateCommitGroups`, `gitCommitConventions`, `gitStatus`, `gitSuggestions`, `gitFlow`,
`gitRangeFlow`, `gitRangeDiffFile`, `gitDiffFile`, `gitHead`, `gitBranches`, `gitCheckout`,
`gitCreateBranch`, `gitWorktrees`, `gitAddWorktree`, `gitLog`, `gitCommitMessage`, `gitFileLog`,
`gitCommitDiff`, and `gitCommitFlow`; `worktreeInbox` belongs to Review. Local schemas encode command
allowlisting, trimmed messages, branch minimums, and log limits/defaults; landed records transcribe
those semantics.

## Scope

Edit `apps/daemon/src/router/git.ts`, add its focused contract test, and remove only `git.ts` from
the temporary lint remaining-file set after all 29 procedures pass.

## Non-goals

Do not run Git against a human checkout, alter command allowlists/env/hardening, change commit-model
providers, move `worktreeInbox`, add error codes, modify operations/helpers, or touch `review.ts`.

## Target ownership and public surface

Every exact name uses its same-name `procedureCatalog` input and output on the existing public
query/mutation. `worktreeInbox` uses the Review-owned catalog entry; the other 28 use Git-owned
entries. Remove local Zod only after every constraint is supplied by the canonical schema.

## Behavior to preserve

Preserve QUICK_COMMANDS enforcement, whitespace/minimum/default/max validation, command output,
staging/discard/commit/push behavior, generation inputs/results, flow/diff/head/branch/worktree/log
shapes, ordering, and inbox filtering. Preserve Git environment safeguards from the audit docs.

Deliberately replace object-input unknown-key stripping with strict rejection through
`request.invalid`; retain no compatibility parser.

## Legacy behavior to delete

Delete all 29 local input definitions and unvalidated outputs in `git.ts`; remove its `zod` import
if unused and remove only `git.ts` from lint's remaining set.

## Ordered implementation

1. Bind the mutation procedures in source order to their exact catalog entries.
2. Bind every Git query and the Review `worktreeInbox` query without changing resolvers.
3. Remove obsolete schema imports, including now-unused `QUICK_COMMANDS` and
   `commitMessageGenerationInputSchema`; retain every command/helper used by resolvers.
4. Add a contract-focused router test covering unknown-key and other constrained invalid input,
   representative valid output, exact `gitLog.limit = 200` and `gitFileLog.limit = 50` defaults,
   and malformed output rejection.
5. Remove `git.ts` from the lint set and prove all 29 exact bindings.

## Tests

Add `apps/daemon/src/router/git.contract.test.ts`. Mock the narrow Git/helper module boundaries; do
not reimplement Git behavior or spawn Git merely to prove tRPC schema attachment.

## Forbidden shortcuts

Do not weaken an enum/refinement/default, execute real destructive Git mutations, classify native
Git failures, retain local Zod, split the router at this stage, or skip `worktreeInbox` because its
domain differs.

- [ ] Git hardening, constraints, limits, results, and helper calls remain unchanged.
- [ ] `git.ts` leaves the ledger and lint proves all 29 bindings.
- [ ] Focused tests, deletion search, repository lint, full verify, and diff check pass.
- [ ] One commit lands only `CON-016`, marks recipe/catalog Landed, leaves a clean worktree, provides

Git source relocation remains later GIT specs.
