# GIT-006 — Cut over Git reads and mutations through shared semantics

- Status: Draft
- Batch: 3 — remaining domain cutovers

- Depends on: GIT-004, GIT-005, TST-001, RT-005

## Objective

Git Changes, Diff, History, Commit and branch clients use shared typed query/mutation/notification definitions and leave only presentation state in app stores.

## Why this unit exists

Web has horizontal `use-git-flow`, `use-diff`, `use-history`, `use-commit` hooks and Git components; mobile splits the same behavior among changes/diff/history/shell hooks and local procedure modules.

## Current behavior and evidence

- `procedures/changes.ts` contains Git schemas and mutations; Web imports backend Git models.
- Current Git change facts are `git.working-tree-changed`; checkout/worktree behavior is already GIT-003/004.
- Draft/selection/history stores hold presentation choices alongside daemon reads today.

## Scope

Add `packages/client-runtime/src/git/{git-reading,git-mutations,git-notifications,index}.ts`; create Web/mobile `features/git/` adapters; move the named Changes/Diff/History/Commit hooks and callers; delete their raw descriptor/model imports.

## Non-goals

Do not redo workspace semantics, change Git operations, move generic Viewer rendering, or put flow/diff/history Query data in stores.

## Target ownership and public surface

Runtime exports typed project-scoped identities for status, flow, range-flow, diff file/reading, head, log/file-log/commit-diff, branches, suggestions, conventions and commit message; mutation definitions for stage/unstage/discard/quick-command/push/commit/generation use authoritative non-optimistic refetch. `gitNotificationEffects` maps working-tree changes to the exact affected identities. App indexes export read/action hooks; stores retain only draft, selected path/range and view mode.

## Behavior to preserve

Keep polling/backstop rules, diff rendering, staging/commit failure messages, commit grouping/conventions, history navigation, branch UI, review marks and external Git refresh.

## Legacy behavior to delete

Delete raw tRPC/mobile descriptor cache strings, `@backend/git` imports, and app-event Git invalidation branches from migrated Git feature code.

## Ordered implementation

1. Verify GIT-005 contracts/operations and RT-005.
2. Add runtime identities/effects and direct tests.
3. Bind Web/mobile feature adapters, move callers, then delete local wire/cache logic.

## Tests

Prove identity dimensions, exact mutation effects/no optimism, notification mapping, contract-valid failures, and retained changes/diff/history/commit component/store behavior.

## Validation and evidence

- Run `pnpm --dir apps/desktop test -- ../../packages/client-runtime/src/git ../web/src/features/git ../mobile/src/features/git ../web/src/hooks/use-git-flow.test.ts ../web/src/hooks/use-history.test.ts`.
- Run `pnpm --dir apps/mobile typecheck` and `pnpm lint`.
- Run `rg -n "@backend/git|procedures/changes|trpc\.git|APP_EVENT_INVALIDATIONS.*working-tree" apps/web/src apps/mobile/src`; it returns no result in migrated Git features.

## Forbidden shortcuts

Do not broad-invalidate, optimistic-paint host effects, retain local schemas, or move presentation rendering to client-runtime.

## Completion criteria

- [ ] Runtime owns Git server semantics and both apps use feature adapters.
- [ ] Query data is absent from presentation stores and legacy paths are deleted.
- [ ] Tests, typecheck, lint and search pass; the unit is committed.

## Handoff

GIT-007 removes remaining non-Git ownership leakage.
