# ACT-004 — Delete Terminal-owned Action descriptors and facades

- Status: Draft
- Batch: 3 — remaining domain cutovers
- Domain: actions
- Depends on: `ACT-003` (Draft), `ACT-001` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [012](../decisions/012-enforce-the-target-architecture.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Delete every Terminal-owned Action contract, client descriptor, UI facade, and compatibility import after canonical Actions adapters are live.

## Why this unit exists

ACT-001 relocates server ownership, but completion requires no surviving Terminal vocabulary that can reintroduce it.

## Current behavior and evidence

Current Actions procedures are in `router/terminal.ts`; Web Action components are under `components/terminal`; mobile mirrors are in `procedures/terminal.ts`; ACT-003 relocates clients and explicit run coordination.

## Scope

Delete only legacy Terminal Action descriptors/imports/exports and update completed-domain architecture gates; keep terminal presentation components only insofar as ACT-003 already repointed them to Actions.

## Non-goals

Do not change command execution, PTY lifecycle, Action semantics, or terminal stream code.

## Target ownership and public surface

Only canonical Actions contract/daemon/client paths name Action data, trust, mutation, or run preparation; Terminal accepts a prepared command only at its explicit stream boundary.

## Behavior to preserve

Preserve all ACT-001/003 visible Action and run behavior.

## Legacy behavior to delete

Delete Action records from `apps/mobile/src/lib/daemon/procedures/terminal.ts`, Terminal router exports, Terminal client facades, and compatibility barrels.

## Ordered implementation

1. Verify canonical callers with import search.
2. Delete legacy definitions and reroute remaining imports.
3. Add zero-result architecture gate assertions.

## Tests

Run Actions Web/mobile adapter tests plus terminal stream regression tests.

## Forbidden shortcuts

Do not retain aliases/re-exports or move Action policy back into Terminal.

- [ ] Legacy Terminal Action ownership has zero definitions/imports.
- [ ] Canonical Actions behavior remains proved; gates pass.

## Handoff

Actions is complete.
