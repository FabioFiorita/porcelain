# CON-008 — Move Board procedure schemas into the Board contract module

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: `board`
- Depends on: `CON-007` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Board owns exact schemas/kinds for `boardCards`, `addBoardCard`, `updateBoardCard`, `moveBoardCard`,
`deleteBoardCard`, and `clearBoardCards`; ledger count falls from 20 to 14.

## Why this unit exists

Board already has a leaf schema but its complete procedure surface remains horizontal.

## Current behavior and evidence

`apps/daemon/src/router/board.ts` declares all six names; `boardCardSchema` is in refined contracts.

## Scope

Create `packages/contracts/src/board/{board.contract,board.procedures,index}.ts`, tests and ledger removal.

## Non-goals

Do not create Board operations/stores, notifications, clients or rename card vocabulary.

## Target ownership and public surface

`boardProcedures` declares `boardCards` query and the other five mutations. `board.contract.ts` owns
strict BoardCard, create/update/move/delete/clear input and list/output schemas.

## Behavior to preserve

Preserve status values, order/createdAt fields and optional body behavior.

## Legacy behavior to delete

Delete only six Board ledger items; horizontal catalog deletion remains `CON-012`.

## Ordered implementation

1. Move/refine Board schemas into the Board module.
2. Export six kind-aware records and inferred types.
3. Remove ledger items and expect 14 unmigrated names.

## Tests

Add valid/invalid fixtures for every record and BoardCard field/default.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/board/board.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not import Review types, use unknown schemas or leave a Board entry in the ledger.

## Completion criteria

- [x] Six exact Board records exist and ledger count is 14.
- [x] Tests, lint script and diff check pass.

## Handoff

`BRD-001` may extend one canonical Board contract entry point.
