# SEA-003 — Delete Files/Git Search ownership and complete Search cutover

- Status: Draft
- Batch: 3 — remaining domain cutovers
- Domain: search
- Depends on: `SEA-002` (Draft), `SEA-001` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [007](../decisions/007-share-nonvisual-client-behavior.md), [012](../decisions/012-enforce-the-target-architecture.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Delete every remaining Files/Git router and mobile Files procedure mirror that presents a Search intention.

## Why this unit exists

Search is incomplete while its canonical contracts/operations coexist with Files router exports and mobile local schemas.

## Current behavior and evidence

`router/files.ts` historically owns the three procedures; mobile Search descriptors are in `apps/mobile/src/lib/daemon/procedures/files.ts`; SEA-001/002 provide target Search router/client semantics.

## Scope

Delete those exact legacy router/client descriptor imports/exports and update architecture migration registry tests for completed Search only.

## Non-goals

Do not change Search UI rendering, Files tree behavior, Git process behavior, query semantics, or introduce aliases.

## Target ownership and public surface

Only `packages/contracts/src/search`, `apps/daemon/src/features/search`, and the SEA-002 client-runtime/app adapters name Search procedures and values; the public flat procedure names remain unchanged.

## Behavior to preserve

Preserve all SEA-001 result/query behavior and both client feature flows.

## Legacy behavior to delete

Delete `searchText`, `searchCode`, `searchFiles` from Files router source; delete mobile Files Search schemas/descriptors and all compatibility re-exports.

## Ordered implementation

1. Verify SEA-001/002 target paths are live.
2. Redirect all callers to canonical Search paths.
3. Delete exact legacy definitions and add zero-import gate assertions.

## Tests

Run Search operation/runtime/Web/mobile adapter tests and architecture import checks; no new E2E.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../daemon/src/features/search/search-router.test.ts ../../packages/client-runtime/src/search/search-queries.test.ts ../web/src/features/files/search-list.test.tsx ../mobile/src/features/files/search-list.test.tsx
pnpm lint
rg -n "search(Text|Code|Files)" apps/daemon/src/router/files.ts apps/mobile/src/lib/daemon/procedures/files.ts
git diff --check
```

## Forbidden shortcuts

Do not leave re-exports, duplicate schemas, or move Search back under Files/Git.

## Completion criteria

- [ ] Legacy sources have zero Search definitions/imports.
- [ ] Canonical paths are the only Search surface and gates pass.

## Handoff

Search is complete; later work changes only its canonical slices.
