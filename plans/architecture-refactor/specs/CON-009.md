# CON-009 — Move Actions procedure schemas into the Actions contract module

- Status: Draft
- Batch: 0 — architecture and contract foundations
- Domain: `actions`
- Depends on: `CON-008` (Draft)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Actions owns six exact procedure records and reduces the ledger from 14 to 8 names.

## Why this unit exists

Actions currently resides in `router/terminal.ts`, despite separate command/trust ownership.

## Current behavior and evidence

Names are `actions`, `trustActions`, `addAction`, `updateAction`, `moveAction`, `deleteAction`.

## Scope

Create `packages/contracts/src/actions/{actions.contract,actions.procedures,index}.ts`, tests and ledger removal.

## Non-goals

Do not run Actions, change trust persistence, move Terminal streams or add a notification.

## Target ownership and public surface

`actionsProcedures` makes `actions` a query and the other five mutations. `actions.contract.ts` owns
strict Action/ActionView, trust IDs, create/update/move/delete values and inferred types.

## Behavior to preserve

Preserve command/title constraints, primary/local location, order, creation and derived trust flag.

## Legacy behavior to delete

Delete only six Actions ledger entries; `CON-012` owns horizontal-file deletion.

## Ordered implementation

1. Translate current terminal-router Action shapes into Actions schemas.
2. Export six kind-aware records.
3. Remove ledger items and expect 8 unmigrated names.

## Tests

Add valid/invalid fixtures including trust IDs and ActionView derived trust.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/actions/actions.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not place the module under Terminal or expose command trust persistence records.

## Completion criteria

- [ ] Six exact Actions records exist and ledger count is 8.
- [ ] Tests, lint script and diff check pass.

## Handoff

`ACT-001` may use Actions contracts without Terminal ownership leakage.
