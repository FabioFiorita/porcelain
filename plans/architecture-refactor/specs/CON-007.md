# CON-007 — Move Review procedure schemas into the Review contract module

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: `review`
- Depends on: `CON-006` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

Review owns exact schemas/kinds for its 29 current procedures, including `worktreeInbox` and layers;
the ledger falls from 49 to 20 entries.

## Why this unit exists

Review has 26 router procedures plus inbox/layers outside it, and `featureReading` is currently an
unknown output.

## Current behavior and evidence

The exact 29-name list is the Review rows in `../inventory/backend.md`; current sources are
`router/review.ts`, `router/git.ts:worktreeInbox`, and `router/settings.ts`.

## Scope

Create `packages/contracts/src/review/{review.contract,review.procedures,index}.ts`, full Review
reading/document/evidence schemas, tests and ledger removal.

## Non-goals

Do not rename feature vocabulary, move stores, alter evidence persistence, extract operations or edit CLI.

## Target ownership and public surface

`reviewProcedures` uses query kind for reads and mutation kind for marks/lifecycle/comments/layer
writes. `review.contract.ts` owns strict Review reading, view, intent/result documents, Evidence,
assets, comments, reviewed marks, archive/publish, explore and layer values; `featureReading` has no
unknown branch.

## Behavior to preserve

Keep current nullability, document media, evidence caps/value shape, comment/mark serialization and
archive/publish result shapes.

## Legacy behavior to delete

Delete only 29 Review ledger entries; `CON-021` deletes old horizontal schema exports.

## Ordered implementation

1. Derive complete serializable schemas from all Review router return values.
2. Export `reviewProcedures` with exact query/mutation kinds.
3. Remove entries and expect 20 unmigrated names.

## Tests

Add valid/invalid fixtures for all 29 pairs, each reading/evidence/document discriminator and
previously unknown `featureReading` output.

## Forbidden shortcuts
