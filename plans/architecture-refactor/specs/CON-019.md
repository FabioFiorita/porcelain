# CON-019 — Bind settings-owned cross-domain procedures to canonical contracts

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: Project Data / supporting contract boundary
- Depends on: `CON-018`
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [010](../decisions/010-type-expected-failures-and-validate-boundaries.md), [011](../decisions/011-test-the-boundary-that-owns-the-risk.md), [012](../decisions/012-enforce-the-target-architecture.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

The ten procedures in `router/settings.ts` use their exact Git, Review, Files, or Project Data
contracts without preserving “settings” as a product domain or changing persistence behavior.

## Why this unit exists

The source file is a historical host grouping: Git owns `commitModels`; Review owns `repoLayers` and
`setRepoLayers`; Files owns `repoScope`; Project Data owns the six notes/disposition/visibility
procedures. File ownership keeps the cutover bounded while later specs relocate those concerns.

## Current behavior and evidence

The six Project Data names are `repoNotes`, `setRepoNotes`, `companionDispositions`,
`companionGitVisibility`, `setCompanionGitVisibility`, and `setCompanionDisposition`. Local inputs
encode layer label/pattern rules, non-empty disposition keys, and exact disposition values. Handlers
use commit-model, layers, scope, notes, Git-exclude, and companion-disposition helpers.

## Scope

Edit `apps/daemon/src/router/settings.ts`, add its focused contract test, and remove only
`settings.ts` from the temporary lint remaining-file set after all ten procedures pass.

## Non-goals

Do not create a Settings domain, relocate helpers/stores, change regex/layer rules, note absence,
disposition openness, visibility effects, commit models, scope shape, persistence, or clients.

## Target ownership and public surface

Bind each exact procedure to `procedureCatalog.<name>.input` and `.output` on its unchanged public
query/mutation. The catalog entry's canonical domain—not the router filename—owns the wire schema.
Keep direct helper calls and return mappings unchanged.

## Behavior to preserve

Preserve model lists, layer validation/default/custom flags, repo scope defaults
`hiddenPaths = []`/`pinnedPaths = []`, empty-string missing notes,
open channel keys, shared/local dispositions, hidden/revealed and changed/untracked results, Git
exclude side effects, void semantics, and filesystem/persistence safety.

Deliberately replace object-input unknown-key stripping with strict rejection and give
`commitModels` its canonical void parser; incompatible supplied input maps to `request.invalid`
without a compatibility path.

## Legacy behavior to delete

Delete the nine existing local inputs, add `commitModels`' missing canonical void input, and delete
all ten unvalidated outputs. Remove `zod` and now-unused local `isValidPattern`; remove only
`settings.ts` from lint's remaining set. Do not introduce a settings contract barrel.

## Ordered implementation

1. Bind `commitModels`, `repoLayers`, `setRepoLayers`, and `repoScope` to their owning entries.
2. Bind all six Project Data procedures in source order.
3. Remove obsolete schema imports and the now-unused local `isValidPattern`, retaining helper and
   return mappings used by resolvers.
4. Add tests for unknown-key/supplied-void rejection, layer constraints, exact repo-scope defaults,
   empty notes, open keys, visibility outcomes, valid outputs, and malformed output rejection.
5. Remove `settings.ts` from the lint set and prove all ten bindings.

## Tests

Add `apps/daemon/src/router/settings.contract.test.ts` using temporary config/project directories and
synthetic channel keys. Never touch the human's companion data or Git index.

## Forbidden shortcuts

Do not invent Settings ownership, close the open channel-key vocabulary, make notes nullable, change
Git visibility/disposition side effects, use real project data, or retain local Zod.
