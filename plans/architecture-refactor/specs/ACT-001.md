## Objective

Move saved Action CRUD/trust and explicit run preparation from Terminal router/store ownership to Actions contracts, operations, and version-1 adapters.

## Why this unit exists

Actions are saved commands with human trust policy, not PTY lifecycle; `router/terminal.ts` currently combines both.

## Current behavior and evidence

`router/terminal.ts` owns `actions`, `trustActions`, add/update/move/delete; `stores/actions-store.ts` persists repo actions and `action-trust-store.ts` persists machine-local command fingerprints keyed by absolute project path.

## Scope

Create `apps/daemon/src/features/actions/{actions-ports,actions-operations,actions-router,actions-store,action-trust-store}.ts` and tests; move six procedures, version-1 persistence, and `prepareActionRun` that returns a trusted command/cwd for an explicit Terminal caller.

## Non-goals

Do not execute a command, create a PTY, change Terminal streams, alter UI, or add implicit trust.

## Target ownership and public surface

Actions records own strict action/trust shapes and errors. `ActionsStore` and `ActionTrustStore` own their distinct version-1 files. `prepareActionRun(repoPath,id)` returns typed `actions.not-found` or `actions.untrusted`; it does not call Terminal. Successful CRUD/trust publishes `actions.changed` after durable write.

## Behavior to preserve

Preserve action ordering/move semantics, current title/command validation, shared/local disposition, command fingerprint trust, CLI two-way files, atomic/corrupt-file behavior, and human-only execution.

## Legacy behavior to delete

Delete Action procedures/store imports from `router/terminal.ts`, unversioned action/trust file shapes, and any Terminal-owned Action descriptor.

## Ordered implementation

1. Complete contract errors/fixtures.
2. Build two explicit adapters and narrow ports.
3. Implement CRUD/trust/run-preparation operations and notifications.
4. Bind Actions router; delete Terminal ownership.

## Tests

Test adapters against temporary files, operations with fakes, trust/run refusal, durable notification ordering, and router mapping.

## Forbidden shortcuts

Do not execute in Actions, trust by title/id, share machine trust with repo data, or retain Terminal forwarding.
