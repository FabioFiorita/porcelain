## Objective

The six network Remote wire procedures (`tailnetStatus`, `setTailnetBind`,
`lanStatus`, `setLanBind`, `funnelStatus`, `setFunnelBind`) each invoke
exactly one bound Remote operation over injected config, listener, Funnel,
and env ports; pairing HTTP, CORS, protocol, and the one `authenticate`
function live in `createRemoteHttp`; LAN/Tailnet/Funnel adapters and the
unversioned `<userData>/config.json` store live under
`apps/daemon/src/features/remote/`; legacy `router/network.ts`,
`net/daemon-http.ts`, `net/{funnel,lan,tailnet,tailnet-listener}.ts`,
`stores/config-store.ts`, and `repo-config.ts` are gone; public error
codes and success-payload `error` fields are unchanged.

## Why this unit exists

Decision 013 assigns pairing, CORS, LAN/Tailnet/Funnel listeners, and
remote access to `remote`. REM-001 moved the six host procedures and the
access store, but `router/network.ts` still orchestrates config mutation
and listener start/stop inside the transport, `createNetworkRouter()`
takes no operations argument, `createDaemonHttp` still owns auth/CORS/
pairing policy under `net/`, and the listener adapters still live in
`net/`. `DaemonOperations.remote` has no network methods, so REM-003
cannot assume a domain-owned listener/HTTP capability.

## Behavior to preserve

- Tailnet / LAN `enabled` on **status** is persisted flag OR env force
  (`=== '1'`). Tailnet / LAN `enabled` on **set** is `input || envForced`.
  Funnel `enabled` is live FunnelState, not the persisted flag.
- `error: 'in-use'` only when a Tailnet/LAN reconcile bound nothing and
  saw `EADDRINUSE`. Funnel `error` is `'unavailable' | 'conflict' | null`
  from `funnelStatus`.
- `setTailnetBind` / `setLanBind` write config then start/stop. Loopback
  is never started or stopped by these operations.
- `setFunnelBind` start/stop then write config. Adapter throws skip the
  config write (they reject before `update`).
- Boot in `server.ts`: start Tailnet / LAN / Funnel when the persisted
  flag is `true` **or** the matching env is `'1'`. Funnel boot failures
  log and do not take down loopback. Tailnet/LAN start failure resolves
  null and does not take down loopback.
- Listeners never bind `0.0.0.0`. Port is `ifaceListenerPort()`.
  Reconcile interval 5_000 ms, timer `unref`. `br-` deny prefix keeps
  its hyphen. Ambiguous 100.64/10 fails closed.
- Config: unversioned `{ tailnetBind?, lanBind?, funnelBind? }`, empty
  `{}`, `<userData>/config.json`, memory cache, home-channel atomic
  tmp+rename, invalid → `.corrupt-${Date.now()}` then empty, missing →
  empty, extra keys rejected by `.strict()`, no `maxBytes`, no `0600`.
  `initConfigDir` required before any read.
- Funnel marker remains unversioned `{ target, url }` at
  `PORCELAIN_FUNNEL_FILE` or `porcelainHomePath('funnel.json')`, mode
  `0o600`.
- HTTP: one `authenticate`; admin sha256 + `timingSafeEqual`; CORS scoped
  never `*`; `/trpc` auth then protocol; `POST /pair` rate 12/60s then
  protocol then 8_192 cap; pairing success `cache-control: no-store`;
  failed exchange `auth.unauthenticated`; GET `/pair` is static; WS
  `/session` + `porcelain.<token>` only; static GET/HEAD unauthenticated.
