# CON-003 — Move Project procedure schemas into the Projects contract module

- Status: Landed
- Batch: 0 — architecture and contract foundations
- Domain: `projects`
- Depends on: `CON-002` (Landed)
- Governing decisions: [005](../decisions/005-contracts-own-the-wire.md), [013](../decisions/013-use-ten-canonical-product-domains.md), [015](../decisions/015-make-a-clean-pre-launch-cutover.md)
- Primary exemplar: no

## Objective

`projects.procedures.ts` owns exact schemas/kinds for `openRepoPath`, `recentRepos`,
`removeRecentRepo`, and `browseDirs`, reducing the ledger from 101 to 97 entries.

## Why this unit exists

Current Project wire names live in `router/repos.ts` and share incomplete `RepoInfo`/browse schemas.

## Current behavior and evidence

`apps/daemon/src/router/repos.ts` declares the four procedures; current `repoInfoSchema` and
`browseDirsOutputSchema` are in `procedures/refined.ts`.

## Scope

Create `packages/contracts/src/projects/{projects.contract,projects.procedures,index}.ts` and tests;
remove only these four ledger entries.

## Non-goals

Do not rename repo vocabulary, open Projects, recents storage, directory browsing, routers or clients.

## Target ownership and public surface

`projectsProcedures` declares `openRepoPath` and `removeRecentRepo` as mutations and `recentRepos`
and `browseDirs` as queries. `projects.contract.ts` owns strict current RepoInfo/browse values and
their inferred wire types.

## Behavior to preserve

Keep current optional `includeWorktrees`, nullable browse path, output ordering and string formats.

## Legacy behavior to delete

Delete only these four `unmigratedProcedureLedger` entries; `CON-012` deletes horizontal schemas.

## Ordered implementation

1. Move/refine the current Project Zod values into `projects.contract.ts`.
2. Create `projectsProcedures` with exact schemas/kinds and root-domain exports.
3. Remove its ledger entries and set the unmigrated count expectation to 97.

## Tests

Add `projects.procedures.test.ts` for all valid/invalid inputs and outputs, including optional
worktree flag and nullable browse root.

## Validation and evidence

```text
pnpm --dir apps/desktop test -- ../../packages/contracts/src/projects/projects.procedures.test.ts ../../packages/contracts/src/procedure-ledger.test.ts
node scripts/lint-procedure-contracts.mjs
git diff --check
```

## Forbidden shortcuts

Do not use a `repos` domain path, a handwritten public interface or an old export alias.

## Completion criteria

- [x] Four Project entries have exact schemas/kinds.
- [x] Ledger count is 97 and Project entries are absent.
- [x] Tests, lint script and diff check pass.

## Handoff

`PRJ-001` may consume the Projects contract entry point without catalog discovery.
