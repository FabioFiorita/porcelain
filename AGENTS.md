Before changing code that uses a library, check its current official documentation (including llms.txt when available) for a built-in pattern, and prefer that over custom helpers or dependencies.

For server changes use the `server-engineering` skill. The architecture check, TypeScript, Oxlint and Oxfmt are the rulebook; the codebase is the example; skills hold the workflow. Use `server-spec` for behaviour specs and `server-verify` for HTTP evidence.
