## Implemented foundations

The repository contains a local Node server with inventory, file preferences, commit-history inspection, prepared Git actions, review-layer metadata, and inert artifact storage. These are server capabilities, not a promise of complete end-user screens.

The browser interface includes connection and disconnection, project and worktree navigation, selection, inventory refresh, and availability information. A disposable playground supports local exploration.

## Planned user experiences

- Full Files, Changes, and History interfaces.
- Agent-facing comments and MCP interaction.
- Isolated artifact rendering and sharing.
- Packaged Electron for macOS.
- Native iPhone and iPad presentation, with Android compatibility in scope.
- Verified remote connections through LAN, Tailscale, or configured HTTPS.

The standalone Node server targets macOS and Linux. Browser testing alone does not establish desktop packaging or native mobile behavior.
